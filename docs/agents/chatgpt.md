# 使用 ChatGPT

Ash 桌面应用的 Agents 窗口提供独立的 ChatGPT 入口。你可以继续已有 ChatGPT 会话、选择模型与思考档位、添加文件，或使用听写和实时语音。本页带你完成一次聊天，并整理会话历史。

## 打开并开始聊天

1. 确认运行 Ash 桌面应用的机器已有有效的 Codex ChatGPT 登录。这个页面复用该登录，登录和续期在原应用中完成。
2. 在 Agents 窗口的活动栏选择 **ChatGPT**，或在命令面板执行 **ChatGPT**（`sessions.open.chatgpt`）。
3. 在侧栏选择**新聊天**，或打开已有会话。
4. 在输入区选择模型，输入要求，按 `Enter` 或选择**发送**。用 `Shift+Enter` 换行。
5. 等待回复，需要中断时选择**停止**。

ChatGPT 页面使用自己的会话历史和模型列表。Ash Agent 的 `/new`、`/compact` 和 Skill 选择不适用于这里；要让 Ash Agent 处理工作区开发任务，返回 **Chat**，参阅 [Agent 概览](/docs/agents/overview.md)。

加载会话、生成回复或进行语音对话时，输入框为只读状态。切换会话或产品入口会保留当前窗口中未发送的草稿；关闭窗口前，另行保存不能丢失的内容。

## 选择模型与思考档位

1. 打开输入区的模型按钮。
2. 如果当前模型有多个档位，使用强度滑杆选择需要的档位。可用选项由账号返回，可能包含即时、思考和 Pro 档位。
3. 要更换模型系列，选择面板标题，进入模型列表。选中模型后，再调整它提供的档位。
4. 确认模型按钮显示你需要的选择，再发送消息。

选择器按当前账号返回的目录展示模型与可选档位。这里的选择用于 ChatGPT 请求，不修改 Ash Agent 的模型配置。生成回复期间不能切换模型。

使用键盘时，上下方向键在面板标题与滑杆之间移动；滑杆获得焦点后，左右方向键调整档位，`Home` 和 `End` 选择首末档位。模型列表中用上下方向键浏览，按 `Enter` 选择，按 `Escape` 返回输入区。

## 添加文件

1. 在输入区选择**添加文件**（**Attach files**），或将文件粘贴、拖入输入区。
2. 等待每个附件显示**已就绪**。
3. 如需补充说明，输入要对文件执行的操作，再发送。也可以只发送文件。

每条草稿最多添加 10 个文件，单个文件不超过 20 MiB，总大小不超过 50 MiB。全部附件就绪后才能发送；上传失败时，在对应附件上选择**重试**或**移除**。文件处理是否成功，以附件状态和服务返回为准。

添加文件后即开始上传。发送前检查内容与接收服务，避免上传不应交给 ChatGPT 的信息；从草稿移除附件不能当作已上传文件被远端删除的证明。

## 使用听写与实时语音

听写把你的话放进输入框，方便检查后发送。实时语音直接与 ChatGPT 交谈，并播放它的回复。

### 听写消息

1. 在输入区选择**听写消息**。
2. 按提示完成听写设置和麦克风授权，然后说出内容。
3. 选择**停止听写**，检查光标处插入的文字，再发送消息。

听写不会自动发送。按 `Escape` 会丢弃尚未完成的语音识别；已经插入的文字仍需自行检查。切换会话或离开 ChatGPT 会取消听写。

### 进行语音对话

1. 确认草稿没有文字或附件。
2. 选择输入区最右侧的**语音对话**按钮，按提示允许使用麦克风。
3. 等待**语音对话进行中**，开始说话并收听回复。
4. 结束时选择**停止语音对话**。

草稿有文字或附件时，最右侧按钮用于发送；回复或语音进行中时，它用于停止。切换会话或离开 ChatGPT 也会停止语音，并释放麦克风。结束语音后，检查重新载入的会话记录再继续文字聊天。

如果提示音频播放被阻止，再次通过**语音对话**按钮启动。语音连接失败时，检查页面错误、麦克风权限、网络和当前账号是否支持该请求。

## 查看执行过程与回答

ChatGPT 使用工具时，同一轮的活动集中在一条持续更新的**执行过程**摘要中：

1. 展开执行摘要，查看各个步骤。
2. 展开**工具调用**或**工具结果**，阅读收到的原始输入或结果。
3. 开始回答后，执行过程会自动折叠，并保留在回答上方。需要复查时重新展开。

部分步骤失败时，摘要继续标明失败。不要只凭最终出现了回答，就认定每一步都成功。执行过程显示的是 ChatGPT 返回的活动记录；本地 Agent 的调试日志使用独立入口。

回答中有引用时，可以选择引用编号展开来源详情。图片、媒体和附件按内容提供预览、播放、打开或下载控件；图表提供的类型、缩放与数据系列控件以实际回答为准。

## 查找并整理会话

侧栏将会话分为**置顶**、各个项目和**最近**，各组可以独立折叠。置顶会话只在置顶组中显示，取消置顶后回到所属项目或最近列表。折叠状态会在重启和切换工作区后保留。

在**搜索会话**中输入会话标题或项目名称。搜索只筛选已经加载的会话，并暂停自动加载。要查更早的记录，清空搜索，再向列表底部滚动以加载更多；加载失败后，可再次滚动重试。

将鼠标移到会话行，或用键盘聚焦该行，可使用**置顶聊天**和**更多操作**。更多菜单提供：

| 操作 | 结果与注意事项 |
| --- | --- |
| **重命名** | 输入一到 256 个字符的名称。 |
| **移至项目** | 在子菜单选择已有项目。加载失败时，重新打开菜单重试。 |
| **归档** | 将聊天归档并从当前列表移除。 |
| **分享** | 确认后创建并复制分享链接。持有链接的人可能看到聊天内容，分享前检查其中的信息。 |
| **删除** | 确认后永久删除该聊天。需要保留的内容应先另行保存。 |

这些操作会修改 ChatGPT 账号中的会话。进行会话管理前，先结束语音并等待历史加载完成。执行后检查列表和提示，确认操作已经生效；不能只凭确认框关闭判断成功。这里提供已有项目的分组与移动入口，不提供新建项目操作。

## 刷新与处理异常

在活动栏的 ChatGPT 图标上打开右键菜单，选择**刷新**，或在命令面板运行 **ChatGPT：刷新**（`sessions.chatgpt.reload`）。回复或会话管理操作尚未结束时，先等待它结束。

| 提示或情况 | 下一步 |
| --- | --- |
| 登录不可用或连接失败 | 在运行 Ash 桌面应用的机器上检查并更新 Codex ChatGPT 登录，再返回刷新。 |
| 发送验证未能完成，消息尚未发送 | 稍后重试，并检查服务返回的验证错误。 |
| 回复中断，消息可能已经发送 | 先刷新当前聊天或检查最近会话，确认服务端记录后再决定是否重发。 |
| 停止请求未获确认 | 同样先检查会话记录，不要立即重复发送。 |
| 使用限额或 403 验证、访问限制 | 按服务提示处理或稍后重试；已有登录不能消除这些限制。 |
| 滚动或内容显示异常 | 执行 **ChatGPT：切换滚动优化**，关闭实验性离屏渲染后检查。 |

## 键盘与无障碍操作

* 使用 `Tab` 和 `Shift+Tab` 在新聊天、搜索、会话、附件、输入框与按钮之间移动。
* 在会话列表中，用上下方向键、`Home` 和 `End` 导航，按 `Enter` 打开会话。
* 在分组标题上按 `Enter` 或空格切换折叠，左右方向键分别折叠和展开。
* 在执行摘要或步骤上按 `Enter` 或空格展开详情。
* 在 ChatGPT 侧栏或编辑器中按 `Alt+F1` 打开无障碍帮助，使用 `Alt+F2` 阅读当前聊天的可选择文本视图。
