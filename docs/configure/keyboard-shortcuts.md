# 设置键盘快捷方式

用键盘快捷方式更快地执行常用操作。Ash 提供图形快捷键编辑器和独立的快捷键 JSON 文件；快捷键不写在普通 settings.json 中。

本文依据 2026 年 10 月 18 日的主分支源码；公开安装包的功能以实际发布版本为准。

## 查找一个命令的快捷键

从管理菜单打开 **键盘快捷方式**，或执行 **首选项：打开键盘快捷方式**（Preferences: Open Keyboard Shortcuts）。图形编辑器在弹窗中打开。

在搜索框中查找要修改的命令。表格列出 **命令**、**快捷键**、**生效条件** 和 **来源**。来源可以是系统、用户、扩展或未分配；同一命令可能有多条绑定。页面中的搜索用于查找快捷键，不是编辑器文本搜索，也不是设置搜索。

也可以直接从命令面板定位：

1. 按 `Ctrl+Shift+P`（macOS：`Cmd+Shift+P`）或 `F1`，搜索目标命令。
2. 选择该命令行右侧的齿轮 **配置快捷键**（**Configure Keybinding**）。
3. 在打开的快捷键弹窗中检查绑定。搜索框已填入 `@command:命令ID`，只显示这个命令。未绑定的命令也可以从这里添加快捷键。

选择齿轮不会执行命令，也不会改变命令历史。完成后选择弹窗右上角的关闭按钮，返回此前的界面。搜索和录制时的 `Escape` 有下文说明的退出、清空或取消作用。

## 缩小查找范围

使用标题栏的更多操作菜单，选择 **显示系统快捷键**、**显示用户快捷键**、**显示扩展快捷键** 或 **显示未分配快捷键的命令**。选择 **显示所有快捷键** 清除查询。

也可以在搜索框输入来源筛选，并结合命令名称或 `@command:`：

| 筛选 | 结果 |
| --- | --- |
| `@source:system` | Ash 的系统绑定；`@source:default` 是同义写法 |
| `@source:user` | 当前 profile 的用户绑定 |
| `@source:extension` | 来自扩展的绑定 |
| `@source:unassigned` | 尚未分配快捷键的命令 |

### 按实际按键查找

选择搜索框旁的 **录制按键**，再按下要查找的完整组合键。搜索框会生成带双引号的精确查询；连续组合键必须完整匹配。这个操作只搜索，不会修改绑定。

按 `Escape` 退出搜索录制，保留查询。在普通搜索框中，默认再按 `Escape` 会清空非空查询；也可以选择 **清空快捷键搜索输入**。

选择 **按优先级排序（从高到低）** 可将高优先级规则排在前面，再次选择恢复按名称排序。比较相同按键时，还要检查 **生效条件**，排序并不保证该行在所有界面都能触发。

搜索操作本身也有可修改的快捷键，按钮提示会显示当前绑定。默认情况下：

| 操作 | Windows 和 Linux | macOS |
| --- | --- | --- |
| 录制按键，搜索框获得焦点时 | `Alt+K` | `Cmd+Alt+K` |
| 切换优先级排序，快捷键页获得焦点时 | `Alt+P` | `Cmd+Alt+P` |
| 清空非空搜索，搜索框获得焦点时 | `Escape` | `Escape` |

## 添加或修改绑定

1. 找到目标命令，使用该行的 **添加** 或 **编辑**。也可以双击行，或用方向键选中行后按 `Enter`。
2. 在居中的录制对话框中按下希望使用的组合键。输入框打开时为空，自动获得焦点。
3. 检查按键预览。即使编辑已有绑定，也需要重新录制完整序列。
4. 在录制框中按不带修饰键的 `Enter` 保存。
5. 等待保存结果，再回到命令适用的界面试用快捷键。

只按 Ctrl、Alt、Shift 等修饰键会显示预览，但不能保存为完整绑定。输入法正在组合文字或按键自动重复时，也不会新增一个录制段。

录制只替换按键，保留该条规则的生效条件和命令参数。需要改动条件或参数时，使用快捷键 JSON。

## 录制连续组合键

Ash 可按顺序记录最多四段组合键。例如先按一组键，再松开后按下一组。它们是按顺序触发的完整序列，不是必须同时按住所有按键。

录满四段后，再录制一段会开始新序列。保存前检查界面中的提示，避免误把第五段追加到原序列。

## 取消或清空录制

在录制框中：

- `Escape` 清空当前草稿；草稿为空时，再按一次取消。
- `Tab` 和 `Shift+Tab` 将焦点留在录制框中。
- 不带修饰键的 `Enter` 用于保存。
- 带修饰键的 Enter 或 Escape 可以作为绑定录制。

未在保存时，选择录制对话框外的背景也可以取消。取消后焦点返回原来的行操作；原行已不在时返回搜索框。

若要把裸 Enter、Escape、Tab 或 Shift+Tab 本身绑定为命令，需要使用 JSON 编辑器，因为图形录制框保留了这些键用于操作界面。

## 使用快捷键 JSON

选择快捷键弹窗标题栏的 **打开键盘快捷方式 (JSON)** ，或执行 **首选项：打开键盘快捷方式（JSON）**。Ash 打开当前 profile 的 `keybindings.json`，可编辑特殊按键、命令参数或上下文条件。

不熟悉格式时，先在图形界面添加一条绑定，再打开 JSON 查看生成的内容。保留其他绑定和注释，修改后保存。不要把普通设置的 `"设置键": 值` 片段粘贴进这个文件。

上下文条件决定绑定在什么界面状态下生效。如果命令只能在特定编辑器或视图中使用，应在对应位置测试，而不是只在快捷键页里按键。

## 设置截图快捷键

在快捷键页中搜索 **聊天：添加截图**（Chat: Add Screenshot），或输入 `@command:workbench.action.chat.attachScreenshot` 精确定位。

| 平台 | 默认快捷键 |
| --- | --- |
| Windows 和 Linux | `Ctrl+Alt+S` |
| macOS | `Control+Command+A` |

修改这条绑定后，应用内截图和全局截图使用同一组按键。桌面应用的全局截图默认关闭；需要在 Ash 处于后台时使用，先到设置中开启 `screenshot.globalShortcut`。浏览器开发界面不支持此全局快捷键。

全局快捷键必须是系统支持的单组按键，不能使用连续组合键。若系统或其他应用已占用它，Ash 会显示通知。选择通知中的 **修改快捷键** 可直接打开对应命令。修改失败时，通知可能说明之前的快捷键仍可使用；不要把保存了新绑定理解成全局注册成功。

开始截图后的选区移动、标注和确认按键，参见[截图与标注](/docs/editing/screenshots.md)。

## 保存失败或没有生效

保存期间，录制、行操作和录制取消会暂时禁用。出现错误时，对话框会显示错误并保留草稿；处理问题后，在录制框中按 `Enter` 重试。

如果 `keybindings.json` 有未保存的修改，先保存或还原该文件，再从图形界面修改绑定。

依次检查：

1. 页面是否明确显示保存成功。
2. JSON 是否有尚未保存的编辑或语法问题。
3. 是否处于同一 profile，以及正确的界面上下文。
4. 连续组合键是否完整输入，是否存在其他冲突绑定。
5. 操作系统或输入法是否先拦截了这组按键。

需要移除自己添加的覆盖时，使用该用户绑定行的移除操作，再重新测试默认行为。
