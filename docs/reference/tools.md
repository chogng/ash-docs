# 工具

工具让 Ash Agent 读取信息、修改工作区、运行验证和访问外部系统。本页帮助你辨认工具用途，并通过执行记录检查 Agent 的结论。实际可用工具取决于当前产品、会话和已启用的能力。

## 工具类别

| 类别 | 用途 | 检查什么 |
| --- | --- | --- |
| 文件读取与搜索 | 查找文件、读取内容、定位文本 | 路径、搜索范围和实际返回的证据 |
| 文件编辑 | 创建或修改文件 | 改动内容和受影响的文件 |
| 命令执行 | 运行构建、测试和开发命令 | 参数、工作目录、输出与退出状态 |
| 浏览器交互 | 读取页面、操作控件或验证网页行为 | 页面地址、操作目标和实际结果 |
| MCP 外部工具 | 调用已连接服务 | 服务器来源、输入参数和外部影响 |
| Advisor 咨询 | 根据已有上下文获得第二意见 | 顾问模型、咨询问题、建议与用量 |
| Skill 读取 | 按需加载工作方法或参考资料 | 来源、所选内容以及它与任务的关系 |

浏览器和外部服务能力需要对应宿主或连接可用。尚未提供或连接的能力，不能仅凭提示词启用。工具可用、允许执行和已成功完成，是三个不同的判断。

## 查找和选择本次聊天使用的工具

工作台可从输入区的 **Add context（添加上下文）→ Tools** 查看当前可用工具：

1. 按名称、说明或来源搜索工具，也可以选择一组工具。
2. 选择具体工具或工具组，会把说明作为上下文附到消息中。附上说明本身不会执行工具，也不会排除其他工具。
3. 要限制本次聊天的工具，选择 **Configure tools**，按 `Enter` 切换单项或整组的启用状态。
4. 选择 **Apply tool selection** 应用；按 `Esc` 放弃尚未应用的更改。
5. 检查输入框上方的工具选择附件，再发送任务。只有工具选择、没有任务文字或其他内容时，不能单独发送。

工具选择在成功发送后仍保留于当前聊天输入区，后续新一轮继续使用；移除工具选择附件可重置。调整选择不会改变正在运行的任务，补充输入也不能替换当前轮的工具选择。

工具仍受当前宿主、扩展、MCP 连接和执行权限约束。选中某项工具不能让断开的服务恢复，也不能免除批准。要查看工具来源，可打开工具引用附件的来源按钮，进入 Tools 设置。

## 一次工具调用包含什么

主模型提出工具名称和参数后，Ash 检查具体动作与权限。获准后执行工具，记录结果，再把结果交给主模型。

| 记录 | 表示什么 |
| --- | --- |
| 工具请求 | 主模型计划调用什么，以及使用哪些参数 |
| 批准请求 | 操作正在等待决定，还不能认定已经执行 |
| 执行结果 | 工具实际返回了什么，是否成功、失败或取消 |
| Agent 回复 | 主模型如何解释结果，以及准备采取什么下一步 |

工具名称本身不决定权限。对文件、网络或外部系统的影响取决于具体参数，完整说明见[权限与批准](/docs/configure/permissions.md)。

## 检查工具活动

在当前会话的工具活动中查看调用参数和结果；需要更完整的执行记录时，打开[执行 Trace](/docs/agents/trace.md)。重点核对：

* 文件路径是否属于要处理的项目。
* 搜索结果是否覆盖关键文件，是否需要继续读取。
* 命令是否真正执行完成，测试是否成功。
* 外部操作影响了哪个账号和资源。
* 最终结论是否由这些结果支持。

命令输出中出现测试名称，不等于测试已经通过；只看到启动信息，也不等于操作已完成。结果未知时，先检查实际状态。

## 查看顾问结果

桌面工作台将 `advisor` 调用与结果合并到 **Advisor** 卡片中。展开可查看建议和结果提供的模型、问题、对话序列与用量；聚焦标题后按 `Enter` 展开或收起。Ash Code 在工具结果中显示建议。

顾问没有自己的工具，不能自行读取新文件或执行建议。主模型发起咨询后可以继续验证并执行任务；手动 `/advisor <问题>` 显示结果后等待你的要求。命令与限制见 [Advisor 文档](/docs/agents/advisor.md)。

## 工具不可用或失败时

| 情况 | 检查方式 |
| --- | --- |
| Tools 中找不到所需工具 | 检查当前宿主是否提供该能力、扩展或 MCP 是否已连接，以及工具选择中是否禁用了它 |
| 附上工具说明后没有调用 | 说明只是上下文；在任务中明确要完成的操作，并检查实际工具活动 |
| 修改工具选择后当前任务仍使用原选择 | 新选择用于后续新一轮；需要马上更改时先停止当前任务，再按新选择提交 |
| 等待批准 | 查看批准请求，不要重复提交同一操作 |
| 返回参数或文件错误 | 核对路径、参数和当前工作区；给出新证据后再试，避免反复提交相同的失败调用 |
| MCP 连接失败 | 查看服务器配置、身份验证和连接错误 |
| 操作中断或结果未知 | 确认是否已产生改动，再决定继续方式；停止任务不会自动回滚工具操作 |

## 扩展工作方法和工具

[Skills](/docs/customize/skills.md) 提供说明、脚本和参考资料，通过 `$name` 选择；[MCP 服务器](/docs/customize/mcp-servers.md) 提供外部工具。Skill 启用或 MCP 配置保存，都不会自动授权其后续操作。
