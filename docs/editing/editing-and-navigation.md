# 编辑文件与导航代码

在 Ash 桌面工作台中，你可以打开文件、修改文本、定位代码，再保存结果。本指南介绍日常编辑、差异视图、问题定位和 Markdown 预览，也说明 Design 画布的自动保存方式。

## 开始之前

打开要处理的项目文件夹，并确认你有文件的写入权限。尚未运行 Ash 时，先阅读[从源码运行](/docs/getstarted/run-from-source.md)。

本文使用界面的英文命令名方便查找；显示语言不同，名称可能会翻译。`Cmd` 指 macOS 的 Command 键。快捷键是默认值，已有自定义绑定时以应用显示为准。

按 `Ctrl+Shift+P`（macOS：`Cmd+Shift+P`）或 `F1` 打开命令面板。输入本文给出的命令名，再选择对应命令。

### 区分内置编辑和语言服务

基础文本编辑、查找、括号处理、折叠和缩略图由 Ash 客户端内置，不需要安装或启用名为 **Code** 的扩展。它们与终端里的 `ash code` 命令不是同一个入口。

语言补全、诊断和语义导航仍取决于对应语言服务及后端连接。基础编辑可用不代表语言服务器已经就绪；功能缺失时，先检查文件的语言模式和[语言服务器状态](/docs/configure/language-servers.md)，不要为了恢复高亮而丢弃未保存草稿。

普通文本和结构化文档使用不同能力。`.ash-doc`、Academic 论文和频道笔记还需要独立安装并授权 **学术论文（实验性）**扩展，步骤见[启用文档编辑器](/docs/editing/documents.md#启用文档编辑器)。

阅读和批注 PDF 需要单独安装、启用并授权 **PDF 查看器**；RIS 和 `.ash-library` 文献库使用 **文献管理器**。它们不随产品预装。步骤与保存限制见[阅读 PDF 与管理文献](/docs/editing/pdf-and-references.md)。

## 打开文件并保存一次修改

1. 在文件资源管理器中打开目标文件。也可以运行 **Open File...** ，或按 `Ctrl+O`（macOS：`Cmd+O`）选择文件。
2. 在正文中单击，让输入焦点进入编辑器，然后修改需要调整的文本。
3. 按 `Ctrl+S`（macOS：`Cmd+S`），或运行 **Save**。
4. 检查有没有保存失败提示，再继续下一项修改。

保存成功后，当前编辑内容会写入该文件。需要新建文本时，运行 **New Untitled Text Editor**，或按 `Ctrl+N`（macOS：`Cmd+N`）；首次保存时选择文件名和位置。

需要使用结构化文档时，先启用对应文档扩展，再运行 **新建文档**，保存为 `.ash-doc`。段落样式、分页，以及从 Markdown 或纯文本转换的步骤，见[创建、排版和转换文档](/docs/editing/documents.md)。

一次替换或多光标编辑改错了，可以先撤销并检查恢复的内容，再保存。不要把关闭标签页当成确认保存成功的办法。

## 在差异视图中修改工作文件

从 **Source Control** 的未暂存更改列表打开一个文本文件，可以在比较的修改侧直接编辑。并排显示时，原始内容在左侧，工作文件在右侧。

1. 打开需要检查的未暂存文件，并将焦点放到修改侧。
2. 编辑文本，按需要使用查找、撤销或重做。悬停提示和补全取决于当前语言支持。
3. 按 `Ctrl+S`（macOS：`Cmd+S`）保存，并检查是否出现错误。
4. 确认保存后的内容，再按[Git 与更改](/docs/sourcecontrol/overview.md)中的步骤暂存。

这里使用同一份工作文件，其他标签页中的未保存修改也会反映在比较中。保存只写入文件，不会自动暂存或提交。

原始侧保持只读。已暂存、历史、已删除文件和二进制比较，以及 Git 的多文件比较仍是只读视图。需要修改现有文件时，打开对应的工作文件，不要在快照中寻找保存入口。

比较上方的面包屑显示文件路径。语言支持符号导航时，还会显示修改侧的标题、函数等符号。选择符号可定位到修改侧的对应位置。长行的显示遵循[换行设置](/docs/configure/settings.md#调整长行和差异视图)，也会应用对应语言的换行配置。

## 保存 Design 画布

在 Agents 窗口的 **Creator > Design** 中，画布更改会自动保存。未命名草稿也会保存在当前用户配置中；重新进入同一工作区的 Design 时，会恢复上次文档。打开已有设计文件后，修改会自动写回该文件。

需要另存一份可交付文件时，在画布上右键选择 **Save a copy**（保存副本），并选择不同的目标位置。需要在其他应用中查看图形时，使用 **Export SVG**；重新打开设计使用 **Open design**。这些操作在画布右键菜单中，无需寻找顶部的手动保存栏。

如果出现无法保存的提示，当前更改仍保留在画布中。先检查目标文件和权限，再从右键菜单选择 **Retry saving**（重试保存）。桌面关闭流程会等待保存；保存失败时先处理错误，不要强制退出。自动保存不代替独立备份，也不会自动发布组件库。

此行为适用于 **Design**。Creator 的其他画布工作空间仍使用各自的手动保存操作。

## 格式化代码

当前文件的语言支持提供格式化能力时，从命令面板运行 **格式化文档**（**Format Document**）；只处理选中区域时，运行 **格式化选定内容**（**Format Selection**）。只读文件和不支持格式化的语言不能通过这些命令修改。

存在多个格式化程序且没有可用的默认选择时，显式格式化会让你选择一个。需要固定当前语言的选择时，在选择器中使用 **配置默认格式化程序…**（**Configure Default Formatter...**）；它保存该语言的 `editor.defaultFormatter` 设置。普通选择只用于当前操作。

开启 `editor.formatOnType` 后，支持此能力的语言服务可以在输入其指定字符时格式化。它不等于每次输入都格式化，也不等于保存时格式化。输入时格式化按语言服务提供的触发字符选择能力，不使用上述默认文档格式化程序选择器。

## 按文件名找到项目文件

不确定文件放在哪里时，可以使用窗口顶部的 **Search commands** 搜索入口。

1. 单击该入口，输入文件名的部分内容。
2. 检查候选项下方的目录路径，避免打开不同目录中的同名文件。
3. 选择目标文件并按 `Enter`。

列表会结合最近打开的文件和工作区中的文件。空输入时主要显示最近打开的文件；输入名称后才会搜索工作区文件。你也可以输入已知的绝对路径；`~/` 路径需要当前文件位置能够解析对应的主目录。

另一种入口是打开命令面板，删除开头的 `>` 后输入文件名。保留 `>` 时，输入会用于筛选命令。

如果只想切换已经打开的文件，运行 **Show All Editors**，选择对应标签页。查找文件中的文本则使用下面的文件内查找，或[项目搜索](/docs/editing/search-and-replace.md)。

## 在当前文件中查找和替换

下面的选项用于 Code 文本编辑器。`.ash-doc`、Academic 论文和频道笔记使用独立的[文档查找与替换](/docs/editing/documents.md#查找和替换文档文字)，不提供这里的正则表达式和选区内查找选项。

1. 单击编辑器，按 `Ctrl+F`（macOS：`Cmd+F`）打开 **Find**。
2. 输入查找内容，查看高亮和匹配计数。
3. 使用 **Next match**、**Previous match** 按钮，或 `F3`、`Shift+F3` 在匹配项之间移动。
4. 要替换内容，运行 **Replace**，或按 `Ctrl+H`（macOS：`Cmd+Alt+F`），填写替换文本。
5. 先使用 **Replace** 检查一个匹配项，再决定是否使用 **All**（**Replace all matches**）处理当前查找范围。
6. 检查修改并保存。

查找框提供 **Match case**、**Match whole word** 和 **Use regular expression**。正则表达式无效时会显示 **Invalid expression**；先修正表达式，再进行替换。

只修改一段文本时，先选中这段内容，再打开查找并启用 **Find in selection**。匹配项和全部替换都会限制在该选区内。退出局部查找前记得关闭这一选项，否则文件其他位置不会出现在结果中。

在查找框内按 `Esc` 可以关闭查找并回到编辑器。文件内查找会随着文本和查找条件更新；跨文件搜索的提交方式见[搜索与替换](/docs/editing/search-and-replace.md)。

## 用多光标修改重复文本

当同一文件中只有几处相同文本需要同步调整时，多光标能让你逐个确认修改位置。

1. 选中要修改的文字。
2. 按 `Ctrl+D`（macOS：`Cmd+D`），把下一个相同位置加入选择。
3. 按需要重复操作，确认所有选区都应当修改。
4. 输入新文本，各选区会同时更新。
5. 单击一个位置恢复单光标，检查结果并保存。

要一次选中相同内容的全部位置，使用 **Select All Occurrences**，默认快捷键是 `Ctrl+Shift+L`（macOS：`Cmd+Shift+L`）。先检查选区范围再输入，尤其是同一个词同时出现在注释和代码中时。

对多行添加相同后缀，可以先选中这些行，再运行 **Add Cursors to Line Ends**，或按 `Shift+Alt+I`。

这些操作按文本选择位置。需要理解变量作用域或跨文件影响的修改，应先检查语言导航结果和相关引用。

## 跳到指定行和列

编译错误、日志或同事给出的行号，可以直接用于定位。

1. 打开对应文件并单击编辑器。
2. 运行 **Go to Line/Column...** ，或按 `Ctrl+G`（macOS：`Cmd+G`）。
3. 输入行号，例如 `42`；需要指定列时输入 `42:8`。
4. 查看预览位置，按 `Enter` 确认跳转。

行号和列号都从 1 开始。输入时编辑器会预览目标位置，确认后光标才移过去。按 `Esc` 取消时，原来的选择保持不变。超出文件范围的数字会被限制到有效位置，检查输入框旁显示的实际行列。

## 查看定义和引用

支持相应语言能力时，可以沿着符号理解代码。

1. 把光标放在函数、变量或类型名称上。
2. 右键选择 **Go to Definition**，或按 `F12`。
3. 想先在当前位置查看定义，使用 **Peek Definition**，默认快捷键是 `Alt+F12`。
4. 查看引用时使用 **Go to References**，默认快捷键是 `Shift+F12`。
5. 阅读后运行 **Go Back** 回到之前的位置，需要再次前进时运行 **Go Forward**。

定义、引用、类型定义和实现跳转取决于当前文件的语言支持。命令不可用或没有结果时，先确认打开的是正确文件，并检查该语言功能是否已经可用；普通文本文件未必有符号导航结果。

当前源码内置 Rust 语言支持，首次请求时可按需准备 `rust-analyzer`。Rust 工具链仍需在项目执行环境中准备。需要检查服务器、设置自己的程序路径或查看启动错误时，运行 **配置语言服务器**，按[语言服务器指南](/docs/configure/language-servers.md)处理。

语法着色和语言服务是不同能力。内置语言使用 Tree-sitter 提供基础着色；看到颜色不代表该语言已经具备定义、引用或诊断服务。当前高亮不运行 TextMate 语法，旧的 `tokenColors`、`textMateRules` 和 `.tmTheme` 配置不再适用。需要调整代码颜色时，使用当前主题及 `editor.semanticTokenColorCustomizations.rules`，见[调整设置](/docs/configure/settings.md)。

## 从问题面板定位错误

**Problems**（问题）集中显示当前语言功能提供的错误、警告、信息和提示。选择底部面板中的 **Problems**，或选择状态栏的问题计数，打开列表。

1. 在面板标题栏的 **Filter problems**（筛选问题）中输入错误消息、文件名或路径的一部分。
2. 选择输入框内的 **Filter**（筛选）按钮，勾选要查看的 **Errors**、**Warnings**、**Information** 或 **Hints**。
3. 展开对应文件，选择问题条目，跳到它的行列位置。
4. 修改并保存文件，再查看诊断是否更新。

**Collapse All**（全部折叠）收起文件分组。**Copy Problems**（复制问题）将当前筛选结果复制为文本，包含文件路径、行列、严重级别、消息和诊断来源，适合粘贴到问题报告或 Agent 对话中。折叠文件分组不会把其中匹配的问题排除在复制结果之外。

显示没有匹配项时，选择 **Clear Filters**（清除筛选），同时恢复文本和严重级别筛选。**当前没有问题**表示没有收到诊断，不表示已经运行所有测试；没有诊断且尚未打开项目时，列表会提示先打开文件夹。

## 预览 Markdown 和数学公式

打开 Markdown 文件后，可以从命令面板运行 **Open Preview to the Side**，在旁边查看渲染结果。**Reopen as Rich Text** 切换到富文本编辑，**Reopen as Source** 回到源码编辑。预览只用于查看；编辑后仍要保存文件。

内置 **Markdown Math** 扩展为 Markdown 预览、富文本和聊天提供公式渲染。可以先在 Markdown 中试写：

```markdown
行内公式：$E = mc^2$。

$$
\frac{a}{b}
$$
```

也支持 `\(...\)`、`\[...\]` 和完整的 `math` 围栏代码块。普通代码示例、转义后的分隔符和未完成的公式保持原文显示。

设置 `markdown.math.enabled` 控制公式渲染，默认开启。需要自定义 TeX 宏时，使用 `markdown.math.macros`。扩展被禁用、后端不可用或某条公式无法渲染时，会保留公式源码；这不会阻止 Markdown 源码编辑。浏览器入口的 Markdown 预览和公式功能需要可用且已授权的后端，离线语法着色不等于公式渲染可用。

## 并排查看两个位置

需要一边阅读调用代码、一边修改实现时，运行 **Split Editor**，或按 `Ctrl+\`（macOS：`Cmd+\`）。在另一个编辑器组打开目标文件后，就能并排阅读和修改。

从搜索结果打开的文件可能处于预览标签页。如果想保留这个标签页，右键标签并选择 **Keep Open**。需要重新打开刚关闭的文件时，使用 **Reopen Closed Editor**，默认快捷键是 `Ctrl+Shift+T`（macOS：`Cmd+Shift+T`）。

需要把文件放到另一块显示器时，可以[把编辑器移至或复制到独立窗口](/docs/editing/workspaces.md#把编辑器放到单独窗口)。复制编辑器窗口仍然编辑同一份文件内容。

## 常见问题

**快捷键没有响应。** 先单击需要操作的编辑器，避免焦点留在终端、聊天输入框或搜索框中。也可以从命令面板运行同名命令。系统占用的按键或自定义绑定可能改变实际行为。

**查找不到明明存在的文字。** 检查大小写、全词和正则选项，以及 **Find in selection** 是否仍然开启。还要确认正在查找正确的文件。

**替换按钮不可用。** 确认文件可以编辑，并且查找表达式有效、存在匹配项。只读编辑器会拒绝替换。

**文件保存失败。** 保留当前编辑器，阅读错误信息，检查目标路径、写入权限或连接状态。处理后再次保存并确认结果，避免继续覆盖或关闭尚未保存的内容。

**按文件名没有找到目标。** 检查项目文件夹是否正确，尝试输入更具体的文件名或已知绝对路径。多个相似候选时，按目录路径确认目标。

## 常用命令

命令 ID 可用于识别同名命令和配置快捷键。

* **Show All Commands**：`workbench.action.showCommands`
* **Open File...** ：`workbench.action.files.openFile`
* **Save**：`workbench.action.files.save`
* **Find**：`actions.find`
* **Replace**：`editor.action.startFindReplaceAction`
* **Go to Line/Column...** ：`workbench.action.gotoLine`
* **Go to Definition**：`editor.action.revealDefinition`
* **Show All Editors**：`workbench.action.showAllEditors`
