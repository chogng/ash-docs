# 编辑文件与导航代码

在 Ash 桌面工作台中，你可以直接打开文件、修改文本、定位代码，再保存结果。本指南从一次普通编辑开始，介绍文件内查找、多光标、行号跳转和定义导航。

## 开始之前

打开要处理的项目文件夹，并确认你有文件的写入权限。尚未运行 Ash 时，先阅读[从源码运行](/docs/getstarted/run-from-source.md)。

本文使用界面的英文命令名方便查找；显示语言不同，名称可能会翻译。`Cmd` 指 macOS 的 Command 键。快捷键是默认值，已有自定义绑定时以应用显示为准。

按 `Ctrl+Shift+P`（macOS：`Cmd+Shift+P`）或 `F1` 打开命令面板。输入本文给出的命令名，再选择对应命令。

## 打开文件并保存一次修改

1. 在文件资源管理器中打开目标文件。也可以运行 **Open File...**，或按 `Ctrl+O`（macOS：`Cmd+O`）选择文件。
2. 在正文中单击，让输入焦点进入编辑器，然后修改需要调整的文本。
3. 按 `Ctrl+S`（macOS：`Cmd+S`），或运行 **Save**。
4. 检查有没有保存失败提示，再继续下一项修改。

保存成功后，当前编辑内容会写入该文件。需要新建文本时，运行 **New Untitled Text Editor**，或按 `Ctrl+N`（macOS：`Cmd+N`）；首次保存时选择文件名和位置。

一次替换或多光标编辑改错了，可以先撤销并检查恢复的内容，再保存。不要把关闭标签页当成确认保存成功的办法。

## 按文件名找到项目文件

不确定文件放在哪里时，可以使用窗口顶部的 **Search commands** 搜索入口。

1. 单击该入口，输入文件名的部分内容。
2. 检查候选项下方的目录路径，避免打开不同目录中的同名文件。
3. 选择目标文件并按 `Enter`。

列表会结合最近打开的文件和工作区中的文件。空输入时主要显示最近打开的文件；输入名称后才会搜索工作区文件。你也可以输入已知的绝对路径；`~/` 路径需要当前文件位置能够解析对应的主目录。

另一种入口是打开命令面板，删除开头的 `>` 后输入文件名。保留 `>` 时，输入会用于筛选命令。

如果只想切换已经打开的文件，运行 **Show All Editors**，选择对应标签页。查找文件中的文本则使用下面的文件内查找，或[项目搜索](/docs/editing/search-and-replace.md)。

## 在当前文件中查找和替换

1. 单击编辑器，按 `Ctrl+F`（macOS：`Cmd+F`）打开 **Find**。
2. 输入查找内容，查看高亮和匹配计数。
3. 使用 **Next match**、**Previous match** 按钮，或 `F3`、`Shift+F3` 在匹配项之间移动。
4. 要替换内容，运行 **Replace**，或按 `Ctrl+H`（macOS：`Cmd+Alt+F`），填写替换文本。
5. 先使用 **Replace** 检查一个匹配项，再决定是否使用 **All**（**Replace all matches**）处理当前查找范围。
6. 检查修改并保存。

查找框提供 **Match case**、**Match whole word** 和 **Use regular expression**。正则表达式无效时会显示 **Invalid expression**；先修正表达式，再进行替换。

只修改一段文本时，先选中这段内容，再打开查找并启用 **Find in selection**。匹配项和全部替换都会限制在该选区内。退出局部查找前记得关闭这一选项，否则文件其他位置不会出现在结果中。

在查找框内按 `Esc` 可以关闭查找并回到编辑器。文件内查找会随着文本和查找条件更新；跨文件搜索的提交方式见[搜索与替换](/docs/editing/search-and-replace.md)。

## 用多光标修改重复文本

当同一文件中只有几处相同文本需要同步调整时，多光标能让你逐个确认修改位置。

1. 选中要修改的文字。
2. 按 `Ctrl+D`（macOS：`Cmd+D`），把下一个相同位置加入选择。
3. 按需要重复操作，确认所有选区都应当修改。
4. 输入新文本，各选区会同时更新。
5. 单击一个位置恢复单光标，检查结果并保存。

要一次选中相同内容的全部位置，使用 **Select All Occurrences**，默认快捷键是 `Ctrl+Shift+L`（macOS：`Cmd+Shift+L`）。先检查选区范围再输入，尤其是同一个词同时出现在注释和代码中时。

对多行添加相同后缀，可以先选中这些行，再运行 **Add Cursors to Line Ends**，或按 `Shift+Alt+I`。

这些操作按文本选择位置。需要理解变量作用域或跨文件影响的修改，应先检查语言导航结果和相关引用。

## 跳到指定行和列

编译错误、日志或同事给出的行号，可以直接用于定位。

1. 打开对应文件并单击编辑器。
2. 运行 **Go to Line/Column...**，或按 `Ctrl+G`（macOS：`Cmd+G`）。
3. 输入行号，例如 `42`；需要指定列时输入 `42:8`。
4. 查看预览位置，按 `Enter` 确认跳转。

行号和列号都从 1 开始。输入时编辑器会预览目标位置，确认后光标才移过去。按 `Esc` 取消时，原来的选择保持不变。超出文件范围的数字会被限制到有效位置，检查输入框旁显示的实际行列。

## 查看定义和引用

支持相应语言能力时，可以沿着符号理解代码。

1. 把光标放在函数、变量或类型名称上。
2. 右键选择 **Go to Definition**，或按 `F12`。
3. 想先在当前位置查看定义，使用 **Peek Definition**，默认快捷键是 `Alt+F12`。
4. 查看引用时使用 **Go to References**，默认快捷键是 `Shift+F12`。
5. 阅读后运行 **Go Back** 回到之前的位置，需要再次前进时运行 **Go Forward**。

定义、引用、类型定义和实现跳转取决于当前文件的语言支持。命令不可用或没有结果时，先确认打开的是正确文件，并检查该语言功能是否已经可用；普通文本文件未必有符号导航结果。

## 并排查看两个位置

需要一边阅读调用代码、一边修改实现时，运行 **Split Editor**，或按 `Ctrl+\`（macOS：`Cmd+\`）。在另一个编辑器组打开目标文件后，就能并排阅读和修改。

从搜索结果打开的文件可能处于预览标签页。如果想保留这个标签页，右键标签并选择 **Keep Open**。需要重新打开刚关闭的文件时，使用 **Reopen Closed Editor**，默认快捷键是 `Ctrl+Shift+T`（macOS：`Cmd+Shift+T`）。

## 常见问题

**快捷键没有响应。** 先单击需要操作的编辑器，避免焦点留在终端、聊天输入框或搜索框中。也可以从命令面板运行同名命令。系统占用的按键或自定义绑定可能改变实际行为。

**查找不到明明存在的文字。** 检查大小写、全词和正则选项，以及 **Find in selection** 是否仍然开启。还要确认正在查找正确的文件。

**替换按钮不可用。** 确认文件可以编辑，并且查找表达式有效、存在匹配项。只读编辑器会拒绝替换。

**文件保存失败。** 保留当前编辑器，阅读错误信息，检查目标路径、写入权限或连接状态。处理后再次保存并确认结果，避免继续覆盖或关闭尚未保存的内容。

**按文件名没有找到目标。** 检查项目文件夹是否正确，尝试输入更具体的文件名或已知绝对路径。多个相似候选时，按目录路径确认目标。

## 常用命令

命令 ID 可用于识别同名命令和配置快捷键。

- **Show All Commands**：`workbench.action.showCommands`
- **Open File...**：`workbench.action.files.openFile`
- **Save**：`workbench.action.files.save`
- **Find**：`actions.find`
- **Replace**：`editor.action.startFindReplaceAction`
- **Go to Line/Column...**：`workbench.action.gotoLine`
- **Go to Definition**：`editor.action.revealDefinition`
- **Show All Editors**：`workbench.action.showAllEditors`
