# 截图与标注

截图由预装的 **Snapshot**（截图，`ash.snapshot`）扩展提供。你可以独立复制或保存屏幕图片，也可以从聊天添加图片；代码图片则从编辑器选区生成。

本文依据当前主分支实现，已发布安装包的功能以实际版本为准。

## 开始截图

选择适合当前目的的入口：

* **独立截图**：运行 **截图：截取屏幕**（Screenshot: Capture Screen），或使用默认快捷键。无需先打开聊天；仅在选择 **加入聊天** 后才会打开聊天并添加到当前草稿。
* **从聊天截图**：在支持图片的聊天中选择 **添加上下文 → 截图…**。本次截图绑定发起时的草稿，切换草稿会取消截图。

按提示处理屏幕访问权限，然后在冻结的屏幕画面上拖动框选区域。选择 **整个屏幕** 可使用完整画面。

默认快捷键为 Windows 和 Linux 的 `Ctrl+Alt+S`，macOS 的 `Control+Command+A`。要修改按键或在 Ash 处于后台时使用，参见[截图快捷键](/docs/configure/keyboard-shortcuts.md)。全局截图默认关闭。

如果使用浏览器开发界面，浏览器会先要求选择屏幕、窗口或标签页；完成选择后再编辑截图。浏览器界面不支持桌面全局快捷键。

## 调整选区并标注

工具栏使用图标按钮，悬停可查看工具名称。

在选区内拖动可移动位置，拖动边缘控制点可调整大小。选择 **坐标** 可按图片像素填写 X、Y、宽度和高度。标注后想继续调整范围，先切回 **选择** 工具。

* **矩形**、**箭头**、**画笔**：标出需要注意的区域。绘制前可选择颜色和线宽。
* **文字**：选择位置后输入说明，按 `Enter` 确认；按 `Escape` 放弃这段文字。
* **马赛克**：遮盖选中的局部区域。分享前检查遮盖效果；敏感内容最好直接裁出截图范围。
* **撤销**：移除最后一个标注。
* **重新截图**：重新获取当前屏幕，开始新的选区和标注。

屏幕画面在开始截图时冻结。原窗口内容改变后，使用 **重新截图** 获取新画面。

## 选择截图去向

| 操作 | 结果 |
| --- | --- |
| **复制** | 将裁剪和标注后的 PNG 图片复制到剪贴板，并结束本次截图 |
| **保存** | 桌面应用选择位置保存 PNG；取消保存对话框返回编辑。浏览器界面下载 PNG 文件 |
| **加入聊天** | 聊天入口添加到原草稿；独立截图打开聊天并添加到当前草稿。都不自动发送消息 |
| **取消** | 结束本次编辑，不添加图片；独立截图不会因此打开聊天 |

**复制** 和 **保存** 不会同时添加聊天附件。选择 **加入聊天** 后，回到输入框检查图片和文字，再发送。若只想本地保存，请直接选择 **保存**。

## 生成代码图片

在文本编辑器中选中代码，右键选择 **截图：生成代码图片**，或从命令面板运行 `snapshot.code`。它使用当前选区，包括尚未保存的编辑，并保留编辑器解析出的语法颜色和字体；不会录制屏幕，也不需要录屏权限。选区过大时，按提示缩小范围后重试。

生成后可以使用相同的标注、复制、保存和加入聊天操作。在 **设置 → 截图 → 代码截图** 中调整边距、缩放、背景、行号、原始行号、窗口装饰、文件名和透明背景。此命令默认未设置快捷键，可以单独绑定。

## 使用键盘操作

选区画面获得焦点时，可使用以下按键：

| 按键 | 操作 |
| --- | --- |
| 方向键 | 移动选区一像素 |
| `Shift` + 方向键 | 调整选区大小 |
| `Ctrl` 或 `Command` + 方向键 | 将移动步长增为 10 像素；可同时按 `Shift` 调整大小 |
| `Ctrl+A` 或 `Command+A` | 选择整个画面 |
| `Ctrl+Z` 或 `Command+Z` | 撤销最后一个标注 |
| `Enter` | 独立屏幕截图和代码图片默认复制；从聊天发起的截图加入原草稿 |
| `Escape` | 取消截图 |

`Tab` 和 `Shift+Tab` 在控件间移动。`Alt+F1` 打开截图帮助，`Alt+F2` 朗读选区坐标和标注数量；屏幕截图的提示不会描述图片内容，代码图片的无障碍内容还包含所选代码文字。在文字标注输入框中，`Enter` 和 `Escape` 只处理当前文字。
