# 协作频道与共享笔记

协作频道让你和其他成员按主题组织共享笔记与通话。本页帮助你加入协作空间、管理频道和成员，并按自己的权限打开笔记或加入通话。频道、成员和已同步的笔记由协作服务器保存，重新打开 Ash 后可以继续使用。

本页依据 2026 年 10 月 20 日的主分支实现。公开安装包中的功能和支持平台以实际发布版本为准。

## 打开协作

在侧边栏选择 **协作**（**Collaboration**），或从命令面板执行 **Open Collaboration**（`ash.collaboration.open`）。编辑器窗口和 Agent 窗口都提供这个入口。

**协作**中包含 **频道**（**Channels**）视图；提供通话服务的窗口还会显示 **通话**（**Calls**）视图。**Agent Teams** 用于组织 Agent 任务，不是这里的人员协作空间。

开始前需要：

* 已连接、支持频道功能的 Ash 后端。
* 可访问的协作服务器，以及空间管理员发给你的完整邀请。创建新空间则需要服务器管理员凭据。
* 要打开频道笔记，需要独立安装、启用并授权 **学术论文（实验性）**（`ash.academic`）文档扩展。详见[启用文档编辑器](/docs/editing/documents.md#启用文档编辑器)，能看到频道不代表笔记编辑器已经可用。
* 要使用频道通话，需要 Ash 桌面应用，且协作服务器已配置 LiveKit。频道和共享笔记本身不要求 LiveKit，浏览器入口也可以使用。

服务器地址使用 HTTPS，填写服务根地址，例如 `https://collaboration.example.com`，不要附加接口路径、查询参数或邀请密钥。本机开发服务可以使用 HTTP。

## 加入或创建空间

### 通过邀请加入

1. 在 **频道**中选择 **连接频道**（**Connect Channels**）。
2. 选择 **通过邀请加入**（**Join with Invitation**）。
3. 粘贴管理员通过 **复制邀请**生成的完整邀请，再按 `Enter`。
4. 检查显示的空间名称、角色和频道列表。

邀请包含服务器地址和成员凭据，不能只粘贴服务器地址。请私下保存和传递，不要发布到公开页面或仓库。邀请代表一个成员身份，管理员应为不同的人分别创建邀请。

### 创建协作空间

已获得服务器管理员凭据时，可以创建空间：

1. 选择 **连接频道 > 创建协作空间**（**Create Collaboration Space**）。
2. 依次填写 **协作服务器**、**服务器管理员凭据**、**空间名称**和 **你的显示名称**。
3. 确认新空间已显示，再创建频道和邀请成员。

创建者成为空间管理员。服务器管理员凭据用于创建空间，不应作为普通成员邀请发给其他人。

## 创建和整理频道

管理员和编辑者可以修改频道，访客只能查看。

* 创建顶层频道：在频道工具栏选择 **新建频道**（**New Channel**），输入名称并确认。
* 创建子频道：打开某个频道的右键菜单，选择 **新建子频道**（**New Subchannel**）。
* 重命名：在频道菜单中选择 **重命名频道**（**Rename Channel**），或聚焦频道后按 `F2`。
* 移除：选择 **移除频道及其子频道**（**Remove Channel and Subchannels**），核对名称和影响范围后确认。

名称不能为空或过长，也不能包含斜杠或控制字符。同一父级下不能有忽略大小写后相同的名称。移除频道会同时移除它的所有子频道，对空间内所有成员生效；关联的频道通话也会关闭。

在 **搜索频道**中输入名称，结果会保留匹配频道的父级，方便确认位置。按 `Escape` 清空搜索。搜索和折叠状态只影响自己的视图，不改变其他人的频道结构。

> [!IMPORTANT]
> 子频道继承整个空间的成员与权限，不是私密频道。需要限制某些资料的受众时，不要仅通过新建子频道来隔离访问。

## 邀请成员和选择权限

选择 **成员和权限**（**Members and Permissions**）查看空间成员。这里列出有访问权的人，不表示他们当前在线。

| 角色 | 频道与笔记 | 频道通话 | 成员管理 |
| --- | --- | --- | --- |
| **管理员**（**Administrator**） | 创建、重命名、移除频道，编辑笔记 | 发起或加入通话，管理通话 | 邀请成员、更改角色、移除成员 |
| **编辑者**（**Editor**） | 创建、重命名、移除频道，编辑笔记 | 发起或加入通话并发言 | 查看成员 |
| **访客**（**Viewer**） | 查看频道和笔记 | 收听已经发起的通话 | 查看成员 |

管理员邀请成员的步骤：

1. 选择 **成员和权限 > 邀请成员**（**Invite Member**）。
2. 输入 **成员显示名称**，选择适合的角色。
3. 选择 **复制邀请**（**Copy Invitation**），私下发给该成员。
4. 请对方按上面的加入步骤连接空间。

要调整现有成员，选择该成员，再选择 **更改角色**（**Change Role**）或 **移除成员**（**Remove Member**）。移除前需要确认撤销该成员的访问权限。空间必须保留至少一位管理员，不能把最后一位管理员改成其他角色或移除。

权限适用于空间中的所有频道、频道笔记和频道通话。移除成员会撤销这些资源的服务器访问；更改角色也会更新笔记与通话权限。已经另存到本地或复制出去的内容不会因此收回。

## 共同编辑频道笔记

1. 选择频道，再选择 **打开频道笔记**（**Open channel notes**）。也可以双击频道，或聚焦频道后按 `Enter`。
2. 等待文档工具栏显示协作已连接。
3. 管理员和编辑者可以编辑；访客可以阅读。

每个频道有一份持续保存的笔记。再次打开同一频道会定位到已有的笔记编辑器；其他成员打开的是同一份共享内容。笔记使用空间成员权限，不需要再输入独立文档邀请，也不通过文档工具栏另行邀请成员。

笔记使用同一套[段落样式、文档查找与页面布局](/docs/editing/documents.md#设置段落和列表)。共同编辑时，不要一边让他人输入，一边替换跨不同字符格式的文字；当前这类替换可能覆盖对方在同段的新内容。先协调暂停编辑、确认同步，再替换并核对结果。

如果权限变化、频道被移除或切换了协作账号，已有笔记连接会失效。看到重新打开笔记的提示时，先保留当前编辑器中尚未同步的修改，再按当前权限重新打开。不要把未同步的本地内容当作已经保存到服务器。

停用、更新或撤销文档扩展授权前，也应先确认笔记已同步并保留需要的内容。扩展不可用且仍有本地修改时，不要反复重新打开同一笔记；详见[文档编辑器不可用时的注意事项](/docs/editing/documents.md#启用文档编辑器)。

协作服务器还需要允许当前文档编辑器的来源。能看到频道但无法连接笔记时，请让服务器管理员检查允许的来源地址和文档协作服务。

## 加入频道通话

1. 在桌面应用中选择频道，再选择 **加入或发起频道通话**（**Join or start channel call**）。
2. 管理员或编辑者可以发起新通话；访客需要等其他成员先发起，再加入收听。
3. 在 **协作 > 通话**中查看连接状态。也可以执行 **Open Calls**（`ash.call.open`）定位到通话控件。
4. 连接后，按需选择 **Unmute microphone** 开启麦克风。麦克风默认关闭，访客不能开启。

同一频道的成员加入同一场当前通话。已经处于另一场通话时，先选择 **Leave**，再加入频道通话。**Leave** 只让自己离开；有管理权限的成员可以用 **End for everyone** 结束通话，之后管理员或编辑者可以重新发起。

频道通话按空间成员身份授权，不显示独立通话的 **Invite speaker** 邀请入口。要增加成员或修改其角色，回到 **成员和权限**。权限变化可能使通话重新连接。

**Stop listening** 暂停播放声音，**Resume listening** 恢复收听；它们与麦克风开关分别控制。通话按钮在浏览器入口中不可用时，请改用桌面应用。桌面仍无法加入时，检查协作服务器的 LiveKit 配置和媒体网络是否可达。

频道笔记从频道入口打开。若通话中需要讨论其他独立共享文档，按[在通话中关联共享文档](/docs/editing/call-documents.md)操作；那些文档仍需自己的邀请权限。

## 断开连接或切换账号

每个本地 Ash 配置保存一个协作账号，同一配置的窗口共用它。要更换空间或成员身份，使用频道工具栏更多操作中的 **连接频道**；要忘记当前保存的账号，选择 **断开此账号连接**（**Disconnect This Account**）。

更换或断开前，先选择 **复制我的登录密钥**（**Copy My Sign-in Key**），私下妥善保存。需要继续时，重新执行原操作并选择 **继续并忘记已保存的账号**。以后可以通过 **通过邀请加入**粘贴自己的登录密钥，恢复同一成员身份。

断开连接不会删除服务器上的频道或移除你的成员身份，也不等于撤销访问权。不要把自己的登录密钥发给其他人；邀请他人应使用 **邀请成员**。

> [!CAUTION]
> 没有保存登录密钥时，需要另一位管理员重新邀请你。如果你是唯一管理员，先保存密钥，再忘记账号。

## 遇到问题

| 现象 | 可以检查什么 |
| --- | --- |
| 提示频道需要连接 Ash 后端 | 当前窗口是否连接到支持频道功能的后端 |
| 能看到频道，但提示文档编辑器不可用 | 文档扩展是否已安装、启用并获得执行授权，包是否支持当前后端平台 |
| 邀请无效或访问被拒绝 | 是否粘贴完整邀请，成员权限是否已被撤销 |
| 频道或权限已更改 | 在更多操作中选择 **刷新频道**（**Refresh Channels**），检查最新状态后重试 |
| 请求中断，不确定是否保存 | 先刷新，确认修改是否已经生效，再决定是否重试 |
| 无法创建或改名 | 检查角色、名称、同级重名和层级；空间最多支持 1,000 个频道、16 层频道结构 |
| 无法读取或保存协作数据 | 检查服务器和当前 Ash 配置的秘密存储是否可用 |
| 访客无法加入通话 | 请管理员或编辑者先发起通话，并确认自己仍是空间成员 |

在频道树中，用上下方向键移动，左右方向键折叠或展开，`Shift+F10` 打开频道菜单。按 `Alt+F1` 查看无障碍帮助，`Alt+F2` 打开文本视图。`accessibility.verbosity.collaboration` 控制聚焦频道树时是否播报帮助提示，默认开启。
