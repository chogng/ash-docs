# 在通话中关联共享文档

**协作**中的 **通话**（**Calls**）视图可以列出正在讨论的共享文档。本页帮助有通话管理权限的成员关联独立共享文档，并让参与者用文档邀请打开它，保留已有的本地编辑。

本页依据 2026 年 10 月 20 日的主分支实现。公开安装包中的功能和支持平台以实际发布版本为准。

## 开始前确认可用入口

从命令面板执行 **Open Calls**（命令 ID 为 `ash.call.open`），打开侧边栏的 **协作**（**Collaboration**）并定位到 **通话**视图。当前窗口需要提供通话服务才会注册这个入口；没有该命令时，检查当前构建和后端服务是否支持通话。

以下步骤从一个已连接的通话开始：

* 独立通话：在 Calls 中选择 **Join with an invitation**，填写提供给你的 **Server address** 和邀请密钥，再选择 **Join call**。
* 频道通话：在桌面应用中选择频道，再选择 **加入或发起频道通话**。服务器需要配置 LiveKit，具体步骤见[协作频道与共享笔记](/docs/editing/channels.md#加入频道通话)。

确认状态为 **Connected** 后继续。

独立文档需要可用的远程协作服务，以及支持其格式的文档编辑器。通话邀请、空间成员身份和独立文档邀请分别控制访问；加入通话或空间不会自动获得这类文档的读取、编辑或成员管理权限。

普通文档、Academic 论文和频道笔记使用的 **学术论文（实验性）**扩展现在需要独立安装、启用并获得执行授权。通话可连接不代表文档编辑器已准备好；先按[文档扩展说明](/docs/editing/documents.md#启用文档编辑器)检查包和后端平台。

频道自带的共享笔记请从 **打开频道笔记**进入。它按空间成员权限授权，不使用本页的独立文档邀请流程。

## 将当前文档关联到通话

只有具备通话管理权限的成员可以关联或取消关联文档：独立通话中是通话所有者，频道通话中是空间管理员。文档本身的协作权限由文档服务单独管理。

1. 在支持协作的文档编辑器中打开要讨论的文档。
2. 如果尚未协作，选择文档工具栏的 **Collaborate**，填写已有房间 ID，或留空创建房间。随后填写远程协作服务器地址和该服务要求的文档令牌，等待连接成功。服务器地址留空使用当前工作台后端的本地协作，不能用于这里的远程文档关联。
3. 保持该文档为当前活动编辑器，在 Calls 视图选择 **关联当前文档**（**Link current document**）。
4. 检查 **此通话中共享的文档** 列表中是否出现文档标题。

一场通话最多保留 32 个文档引用。再次关联同一服务器、同一房间的文档会更新该引用，不会增加重复条目。达到上限时，先取消不再需要的关联。

关联条目包含文档标题、服务地址和房间等识别信息，不包含文档正文或邀请令牌。关联前确认这些信息适合向通话参与者显示。

## 打开通话中的文档

1. 在 Calls 的文档列表中选择 **打开文档**（**Open document**）。
2. Ash 打开一个新的未命名文档编辑器，并显示 **协作令牌** 对话框。
3. 核对对话框中的文档服务器，输入该文档服务提供的邀请令牌。通话邀请密钥不能代替它。
4. 等待文档协作连接成功，再查看内容或按自己的文档权限编辑。

每次打开都会使用新的未命名工作副本，不覆盖已经打开的本地文件。这份副本连接原来的共享文档，协作编辑仍会影响共享内容，并非脱离协作的独立备份。需要留存本地文件时，检查内容后另行保存。

使用新增的[文档查找与替换](/docs/editing/documents.md#查找和替换文档文字)时，先与其他编辑者协调。当前跨不同字符格式的替换可能覆盖同段中他人刚输入的文字；先暂停共同编辑并确认同步，再替换和核对。

等待加入时，不要先在新编辑器中输入内容。如果这时产生了本地修改，Ash 会停止加入以保护修改。保留需要的内容，再从通话列表重新打开一个新的副本；不要直接覆盖原草稿。

## 取消关联与收回权限

有通话管理权限的成员在文档条目旁选择 **取消文档关联**（**Unlink document**），可从当前通话的列表移除入口。关联、打开和取消关联都需要通话处于已连接状态。离开或结束通话也不会自动撤销独立文档的访问权。

> [!IMPORTANT]
> 取消关联不会撤销文档权限，也不会断开参与者已经建立的文档协作连接。他们仍可按原有权限继续访问和编辑。需要收回访问权时，由有权管理该文档成员的人在文档协作工具栏的 **Manage collaborators** 中处理。

## 遇到问题

| 现象 | 可以检查什么 |
| --- | --- |
| 看不到关联或取消关联按钮 | 独立通话中是否为所有者，或频道通话中是否为空间管理员；普通参与者只能打开文档 |
| 操作按钮不可用 | 通话是否显示 **Connected**，或是否还有操作正在进行 |
| 提示先开启远程协作 | 当前活动标签是否为支持协作的文档，且已连接远程文档服务 |
| 提示启用文档编辑器或格式不兼容 | 对应文档扩展是否已安装、启用并获得执行授权，是否支持当前后端平台和文档格式 |
| 输入通话密钥仍无法打开文档 | 向文档管理者取得该文档服务的独立邀请令牌，并核对服务器 |
| 提示需要新的未命名编辑器 | 保留已有修改，再从通话列表打开新的副本 |

用 `Tab` 和 `Shift+Tab` 在 Calls 控件间移动，用 `Enter` 或空格选择按钮。Calls 获得焦点时，`Alt+F1` 可查看无障碍帮助；`accessibility.verbosity.calls` 控制聚焦时是否播报键盘帮助，默认开启。
