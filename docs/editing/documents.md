# 创建和转换文档

在 Ash 的 Code 工作台中，你可以新建 `.ash-doc` 文档，或将当前文本、Markdown 转换为独立文档。本页介绍创建、保存和导出流程，以及转换时需要注意的格式限制。

本页依据 2026 年 10 月 18 日的主分支实现。公开安装包中的功能和支持平台以实际发布版本为准。

## 新建并保存文档

1. 按 `Ctrl+Shift+P`（macOS：`Cmd+Shift+P`）打开命令面板。
2. 运行 **新建文档**（**New Document**），打开新的未命名文档。
3. 在正文中输入内容。
4. 按 `Ctrl+S`（macOS：`Cmd+S`），选择保存位置，并保留 `.ash-doc` 扩展名。
5. 检查是否出现保存错误，再继续编辑。

也可以从文件菜单选择 **新建文档**。已有的 `.ash-doc` 文件可从文件资源管理器打开。

需要修改文件名或保存位置时，继续使用 `.ash-doc`。另存为 `.md`、`.txt` 或其他扩展名不会转换文档格式，Ash 会要求使用受支持的扩展名。导出其他格式请使用下文的转换命令。

## 将当前文本转换为文档

转换使用当前文本编辑器中的内容，包括尚未保存的修改。结果会在新的未命名文档中打开，源文件及其未保存修改保持原样。

1. 打开要转换的文本文件或 Markdown 源文件，并让它成为当前活动编辑器。
2. 在命令面板中选择适合的命令：
   * **将当前文本转换为文档**（**Convert Active Text to Document**）：按纯文本转换，保留 `#`、`*` 等字符原样。
   * **将当前 Markdown 转换为文档**（**Convert Active Markdown to Document**）：将受支持的 Markdown 结构转换为文档内容。
3. 检查新文档中的文字、列表、表格和图片。
4. 保存为新的 `.ash-doc` 文件。

Markdown 转换支持标题、段落、粗体、斜体、行内代码、代码块、引用、有序列表、无序列表、分隔线、链接、图片和受支持的表格。

### 处理链接和图片

Markdown 中的相对链接和图片路径以源文件位置为基准。源文件尚未保存时，相对目标会阻止转换；先保存源文件，再重新转换。

转换会读取并内嵌本地 PNG、JPEG、WebP 和 GIF 图片。确认图片存在且 Ash 有读取权限。HTTP 和 HTTPS 图片保留远程地址，转换不会把它们下载为离线副本。

### 处理不支持的 Markdown

HTML、任务列表、删除线、链接标题、图片标题或图片格式，以及带对齐设置的表格等内容不在当前转换范围内。遇到这些内容，Ash 会停止转换，并提示无法保留的内容及源文件的行号、列号。

根据提示调整源内容后重试。需要保留原始内容时，先制作副本。只需要文字时，也可以改用 **将当前文本转换为文档**，但 Markdown 标记会保留为普通字符。

## 导出 Markdown 或纯文本

1. 选择要导出的文档标签页，使文档成为当前活动编辑器。
2. 在命令面板中运行 **将文档导出为 Markdown**（**Export Document as Markdown**），或 **将文档导出为纯文本**（**Export Document as Plain Text**）。
3. 检查新打开的 `.md` 或 `.txt` 文本草稿。
4. 按 `Ctrl+S`（macOS：`Cmd+S`），选择保存位置。

导出会创建独立的未保存文本草稿，不会覆盖原文档，也不会替你保存原文档中的修改。

Markdown 导出只保留受支持的结构。字体、字号等文档样式，以及没有 Markdown 表头、多行单元格或列数不一致的表格，会阻止导出并显示错误。先保留 `.ash-doc` 原件，再决定是否调整格式。

纯文本导出只提供文字，不保留文字样式、链接地址或图片本身；图片会使用替代文字。检查结果后再交付。

当前文档转换命令不提供 Word `.docx` 或 PDF 导入导出。

## 区分普通文档和 Academic

**新建文档**创建普通 `.ash-doc` 文档，不要求论文的标题、摘要或章节结构。

**学术论文（实验性）**（Academic (Experimental)）扩展继续支持已有的 `.ash-academic` 和 `.ash-paper` 文件。需要编辑这些文件时，保持对应扩展启用。不要仅通过修改扩展名，把 Academic 文件当作普通文档打开。

## 使用键盘和无障碍视图

用 `Tab` 和 `Shift+Tab` 在文本块与格式控件之间移动，在文本块内用方向键移动。标准撤销、重做和保存命令仍可使用。

文档获得焦点时，**打开无障碍视图**（**Open Accessible View**）可按文本阅读内容。按 `Escape` 关闭帮助或无障碍视图并返回文档。`accessibility.verbosity.document` 控制文档获得焦点时的无障碍帮助播报，默认开启。
