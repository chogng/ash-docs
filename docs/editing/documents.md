# 创建、排版和转换文档

在 Ash 的 Code 工作台中，你可以新建 `.ash-doc` 文档，设置段落样式、分页与分节，添加批注和块级修订，并转换 Markdown、纯文本或受支持的 DOCX，也可导出 PDF 页面图像。本页帮助你启用文档编辑器，完成编辑和保存，再选择适合交付的文件格式。

本页依据 2026 年 10 月 20 日的主分支实现。公开安装包、扩展市场中的可用版本及支持平台以实际发布内容为准。

## 启用文档编辑器

普通 `.ash-doc`、Academic 论文和频道笔记都由 Academy 文档编辑器提供。它在扩展界面的名称仍是 **学术论文（实验性）**（Academic (Experimental)），扩展 ID 为 `ash.academic`。它已改为独立安装的扩展，不随 Ash 产品包内置；只有 Code 扩展不能打开这些结构化文档。

1. 在命令面板运行 **打开扩展**（**Open Extensions**）。
2. 搜索 `Academic`，检查是否有适用于当前 Ash 版本和后端平台的包。打开详情，核对来源、版本和说明，再选择 **安装**（**Install**）。对应发行包的 ID 为 `ash/academic`。
3. 安装后，在同一包的详情中检查 **启用**（**Enable**）状态，并按提示选择 **授权执行**（**Authorize execution**）。
4. 阅读授权内容后决定是否继续。安装、启用和执行授权是不同步骤；看到已安装不代表文档编辑器已经可用。

执行授权允许该精确版本的原生程序使用当前用户级别的文件、网络和子进程能力，也允许文档客户端接触打开的文档及未保存内容。只授权你信任的来源；包内容或所需契约变化后可能需要重新授权。

源码中具备安装机制不代表线上市场已发布该包。搜索不到时，先核对发行说明和包的实际可用性，不要靠改扩展名或安装不明来源的同名包绕过检查。浏览器入口也需要连接可运行该扩展的已授权后端，不能只靠浏览器离线使用。

> [!CAUTION]
> 停用、撤销授权、更新或卸载前，先保存文档并确认结果。扩展退出后，已有视图会冻结为只读，未保存内容和工作副本仍保留。恢复可用的扩展后，重新打开文档以接续工作副本；旧视图不会自行恢复编辑。重新打开失败时，Ash 保留已有的未保存视图及关闭确认。保留当前标签页并处理错误，不要把恢复保护当作保存成功。

## 新建并保存文档

1. 按 `Ctrl+Shift+P`（macOS：`Cmd+Shift+P`）打开命令面板。
2. 确认文档编辑器可用后，运行 **新建文档**（**New Document**），打开新的未命名文档。
3. 在正文中输入内容。
4. 按 `Ctrl+S`（macOS：`Cmd+S`），选择保存位置，并保留 `.ash-doc` 扩展名。
5. 检查是否出现保存错误，再继续编辑。

也可以从文件菜单选择 **新建文档**。已有的 `.ash-doc` 文件可从文件资源管理器打开。

需要修改文件名或保存位置时，继续使用 `.ash-doc`。另存为 `.md`、`.txt` 或其他扩展名不会转换文档格式，Ash 会要求使用受支持的扩展名。导出其他格式请使用下文的转换命令。

## 设置段落和列表

将光标放入段落，或选择要调整的多个段落，再使用文档中的格式控件：

* **段落样式**：选择 **正文** 或 **标题 1** 到 **标题 6**。Academic 文件仍需满足其论文结构约束。
* **段落排版**：调整对齐方式、段落字体、段落字号、行距、段前和段后间距。
* **起始端缩进**、**末端缩进**和 **首行缩进**：按段落方向设置缩进。首行缩进的负值用于悬挂缩进。
* **Bold**、**Italic**、**Font** 和 **Size**：调整选中文字的字符格式，与整段的排版设置分开。

多个所选段落的属性不同时，控件显示 **混合**。选择新值会应用到所选段落；不要把“混合”当作一种文档样式。

光标位于有序列表中时，**列表编号**提供 **编号起始值**和 **编号格式**。起始值必须是正整数；格式支持数字、大小写字母和大小写罗马数字。嵌套列表中修改的是光标所在的最内层列表。

### 复用命名段落样式

1. 先把一个正文或标题段落调整为需要的排版。
2. 在 **样式名称**中输入名称，选择 **创建样式**。
3. 选择另一个段落，在 **段落样式**列表中选用这个名称。
4. 需要统一修改时，调整一个使用该样式的段落，再选择 **从段落更新样式**。

命名样式保存在当前文档中，不是所有文档共享的模板。每份文档最多有 100 个命名样式，名称最多 80 个字符。

应用样式会保留段落已有的局部排版和字符格式。想让段落跟随命名样式时，选择 **重置段落局部格式**；这不会清除选中文字上的粗体、斜体或其他字符格式。更新样式会影响同一文档中引用它的段落，但各段落的局部覆盖仍优先。

**删除样式**移除样式定义，同时保留已有段落的有效外观，不会删除正文。这些操作可以撤销；检查结果后再保存。

## 查找和替换文档文字

1. 让文档获得焦点，按 `Ctrl+F`（macOS：`Cmd+F`），或选择 **查找与替换**。
2. 在 **查找文本**中输入普通文字，按需要开启 **区分大小写**或 **全字匹配**。
3. 使用 **上一个匹配**、**下一个匹配**，或在查找框中按 `Shift+Enter`、`Enter`。到达首尾后会循环查找。
4. 在 **替换为**中输入新文字，先用 **替换**检查一处，再决定是否使用 **全部替换**。
5. 检查结果并保存。按 `Escape` 或选择 **关闭查找**返回文档。

查找可以跨越同一段文字内的粗体、斜体等字符格式，也包括列表项、表格单元格和代码块中的文字。它不会跨越块边界、图片、引用标记或硬换行。这里按普通文字匹配，不提供代码编辑器的正则表达式或选区内查找选项。

只读文档可以查找和跳转，但不能替换。每次替换或全部替换各占一个撤销步骤；查找条件与高亮只属于当前视图，不保存到文档。

共同编辑时，普通查找替换会保留未被替换部分的文字修改。结构性替换与他人的改动无法合并时，Ash 会报错、停止重试提交，并保留本地编辑。此时先保存或复制需要保留的内容，再与其他成员核对版本；报错后的本地内容不等于已同步到服务器。

## 使用 A4 或 Letter 页面

在 **页面布局**中，将 **纸张**从 **连续**改为 **A4** 或 **Letter**。正文会分页，页面上下堆叠，向下滚动查看后续页面。

* **页边距**统一调整页面四边，提供 36、54、72、108、144 磅选项，默认 72 磅。
* 在 **分页选项 > 纸张方向**中选择 **纵向**或 **横向**。
* 纸张、方向和页边距属于文档内容，保存后保留，也可以撤销和同步给协作者。
* **页面缩放**提供 50% 到 200% 的选项，只改变当前视图的显示大小，不改变正文换行、文档内容或其他人的视图。只读分页文档也可缩放。
* 没有分节时，回到 **连续**可取消页面显示。连续模式不启用页边距和页面缩放控件。有分节时，页面控件按光标位置作用于当前节或未分节部分。

分页后的正文仍然可以编辑。同一段落跨页时，方向键、选区以及复制、剪切、粘贴继续作用于正文；查找跳转也会定位到对应页面。

### 控制段落和表格分页

将光标放入段落，或选择多个段落，展开 **分页选项**：

* **段前分页**：让该段从新页开始。按 `Enter` 创建后续段落时，不会把这个分页设置复制到新段落。
* **与下段同页**：在页面能容纳时，让该段与后续段落保持在同一页。
* **段中不分页**：在页面能容纳时，把整个段落放在同一页。
* **孤行控制**：避免段落只有一行留在页首或页尾，默认开启。

多个所选段落的规则不同时，控件显示 **混合**。选择新值会应用到所选段落。按 `Escape` 收起分页选项并返回正文。

普通表格行会整体移到下一页；高于一页的行仍需要拆分。表格单元格、列表和代码行沿同一正文位置继续编辑。当前不提供重复表头、自定义表格行拆分策略、浮动对象、文字环绕或多栏排版。

### 设置页眉、页脚和页码

1. 在 **分页选项**中填写 **页眉**和 **页脚**。
2. 按需开启 **页码**，在页脚显示当前页与总页数。
3. 开启 **奇偶页不同**时，另填 **偶数页页眉**和 **偶数页页脚**。
4. 要让首页不显示这些内容，开启 **首页不同**。有分节时，它作用于当前节的首页。

页眉页脚只支持单行纯文本，每项最多 500 个字符。页面上的重复文字不是正文编辑区，应回到控件修改。当前不提供富文本页眉页脚、脚注、尾注、自动目录或交叉引用。

### 为后续内容开始新节

1. 把光标放在要开始新节的正文块中。
2. 选择 **在此开始新节**（**Start section here**）。新节从该块开始，不会从段落中间拆开。
3. 在新节中调整纸张、方向、页边距或页眉页脚。
4. 要取消该节，选择 **删除分节符**（**Remove section break**），将内容并回前一节或未分节部分，并检查合并后的页面设置。

各节继承文档的默认页面设置，也可单独覆盖。页码按整个文档连续计算。分节修改可撤销，并随原生文档保存；它不是另建一份文档。

> [!IMPORTANT]
> 物理输入法、完整 Electron 工作台、远程环境和屏幕阅读器仍有待完成的验收范围。在实际使用的平台上先用副本检查关键编辑流程；页面显示也不保证与目标 Word 版本的逐页排版一致。

## 添加批注和审阅修订

在 **审阅**中填写 **审阅作者**，选择正文文字，再输入 **批注内容**并选择 **添加批注**。批注列表保留作者、内容和引用文字；使用 **转到批注**定位原位置，或选择 **解决批注**、**重新打开批注**和 **删除批注**。批注位置会随正文修改调整。

需要记录接下来的修改时，将 **跟踪块级修订**设为 **开启**。审阅列表显示该块的修改前文字与当前文字：

* **接受块级修订**保留当前内容，并移除该审阅记录。
* **拒绝块级修订**恢复整个块最初记录的内容。
* 分节、跨块移动等结构变化可能合并为一个文档结构修订，使用 **接受文档修订**或 **拒绝文档修订**整体处理。

> [!CAUTION]
> 这里记录的是块级基线，不是逐字修订或逐字作者归属。同一块的后续编辑会并入同一个审阅单元，拒绝时会一起恢复；一个块也可能包含表格或整节。共同编辑时，先与其他成员确认要保留的内容，再拒绝修订。接受或拒绝仍可撤销。

批注和修订随原生文档保存，**打开无障碍视图**也可按文本读取。只读文档和冻结的旧扩展视图不能修改审阅记录。导出 PDF 不包含批注列表或修改前后的审阅对照。

## 将当前文本转换为文档

转换使用当前文本编辑器中的内容，包括尚未保存的修改。结果会在新的未命名文档中打开，源文件及其未保存修改保持原样。

1. 打开要转换的文本文件或 Markdown 源文件，并让它成为当前活动编辑器。
2. 在命令面板中选择适合的命令：
   * **将当前文本转换为文档**（**Convert Active Text to Document**）：按纯文本转换，保留 `#`、`*` 等字符原样。
   * **将当前 Markdown 转换为文档**（**Convert Active Markdown to Document**）：将受支持的 Markdown 结构转换为文档内容。
3. 检查新文档中的文字、列表、表格和图片。
4. 保存为新的 `.ash-doc` 文件。

Markdown 转换支持标题、段落、粗体、斜体、行内代码、代码块、引用、有序列表、无序列表、分隔线、链接、图片和受支持的表格。

### 处理链接和图片

Markdown 中的相对链接和图片路径以源文件位置为基准。源文件尚未保存时，相对目标会阻止转换；先保存源文件，再重新转换。

转换会读取并内嵌本地 PNG、JPEG、WebP 和 GIF 图片。确认图片存在且 Ash 有读取权限。HTTP 和 HTTPS 图片保留远程地址，转换不会把它们下载为离线副本。

### 处理不支持的 Markdown

HTML、任务列表、删除线、链接标题、图片标题或图片格式，以及带对齐设置的表格等内容不在当前转换范围内。遇到这些内容，Ash 会停止转换，并提示无法保留的内容及源文件的行号、列号。

根据提示调整源内容后重试。需要保留原始内容时，先制作副本。只需要文字时，也可以改用 **将当前文本转换为文档**，但 Markdown 标记会保留为普通字符。

## 导出 Markdown 或纯文本

1. 选择要导出的文档标签页，使文档成为当前活动编辑器。
2. 在命令面板中运行 **将文档导出为 Markdown**（**Export Document as Markdown**），或 **将文档导出为纯文本**（**Export Document as Plain Text**）。
3. 检查新打开的 `.md` 或 `.txt` 文本草稿。
4. 按 `Ctrl+S`（macOS：`Cmd+S`），选择保存位置。

导出会创建独立的未保存文本草稿，不会覆盖原文档，也不会替你保存原文档中的修改。

Markdown 导出只保留受支持的结构。页面设置、分节、批注与修订、命名段落样式、字体、字号、段落排版和特殊列表编号，以及没有 Markdown 表头、多行单元格或列数不一致的表格，会阻止导出并显示错误。先保留 `.ash-doc` 原件，再按提示决定是否调整格式。

切回 **连续**或删除最后一个命名样式，仍可能保留页面或样式设置，不能保证恢复 Markdown 导出。不要通过改扩展名或直接删改文件内部字段来强行转换；只需要文字时，改用纯文本导出并检查结果。

纯文本导出只提供文字，不保留文字样式、链接地址或图片本身；图片会使用替代文字。检查结果后再交付。

## 导入和导出 DOCX

### 导入 Word 文档

1. 在命令面板或文件菜单中运行 **导入文档文件…**（**Import Document File…**）。
2. 选择 `.docx` 文件。
3. 检查新打开的未保存文档，尤其是文字、样式、表格、分节和审阅内容。
4. 按 `Ctrl+S`（macOS：`Cmd+S`）保存为 Ash 原生文档。

普通 Word 文件导入为 `.ash-doc`。导入不会覆盖源 DOCX；遇到不能保留的结构或格式时，会停止并提示原因，不会生成部分导入的草稿。当前导入入口不支持 PDF。

### 导出 Word 文档

1. 激活要导出的文档，先完成正在进行的输入法输入。
2. 运行 **导出文档文件…**（**Export Document File…**）。
3. 选择 **Word 文档（DOCX）**，再选择与原文档不同的输出文件。
4. 在接收方使用的应用中检查结果。

支持的 DOCX 内容包括段落、标题、字符格式、段落样式、列表、表格、内嵌图片、分节、基础页眉页脚、页码、批注和段落插入或删除修订。远程图片必须先成为内嵌图片；仅保留 HTTP 或 HTTPS 地址的图片会阻止 DOCX 导出。

Ash 导出的 DOCX 在标准内容没有变化时，重新导入可以保留原文档类型、论文结构、引用和审阅信息。外部应用修改文件后，Ash 会解析实际的 Word 内容，不能依赖原来的附带快照恢复所有原生语义。

当前不承诺完整 Word 兼容性。宏、合并单元格、复杂域、公式、脚注、尾注和浮动对象不在受支持范围内。复杂结构审阅不保证与 Word 的修订粒度一致。目标 Word 版本中的打开、编辑和再次保存仍需实机核对；原生往返测试不能代替这一步。

输入或输出上限为 64 MiB；DOCX 解压后总量也不超过 64 MiB，最多 2,000 个 ZIP 条目。保留原生文档作为继续编辑的原件，导出不会替你保存它。

## 导出 PDF 页面图像

1. 激活要导出的文档，检查纸张、页边距、分节和页眉页脚。
2. 完成正在进行的输入法输入，运行 **导出文档文件…**。
3. 选择 **PDF（页面图像）**，再选择输出文件。
4. 打开生成的 PDF，检查首页、末页和跨页内容。

输出使用开始导出时的内容，等待字体和图片准备完成后按页面生成图像。连续正文按 A4 输出；已设置的 A4、Letter 和混合分节页面保留相应尺寸。导出期间后续输入不会进入这一份输出；关闭文档或停用扩展会取消尚在进行的转换。

当前 PDF 每页为 192 dpi 图像，不含可搜索或复制的文字层，也不含批注列表和修订对照。上限为 256 页或 64 MiB，不提供原生打印对话框。需要可编辑文件时保留 `.ash-doc` 或使用受支持的 DOCX。

导出 PDF 不需要安装 PDF 查看器。在 Ash 内阅读和批注 PDF 需要独立的可选扩展，见[阅读 PDF 与管理文献](/docs/editing/pdf-and-references.md)。

## 区分普通文档和 Academic

**新建文档**创建普通 `.ash-doc` 文档，不要求论文的标题、摘要或章节结构。

同一个 **学术论文（实验性）**扩展继续支持已有的 `.ash-academic` 和 `.ash-paper` 文件，它们使用论文结构。普通文档和论文都需要该扩展已安装、启用并获得执行授权。不要仅通过修改扩展名，把 Academic 文件当作普通文档打开。

### 在 Academic 论文中维护引用

Academic 论文提供 **参考文献**和 **引用**工具栏操作，普通 `.ash-doc` 和频道笔记不提供这些论文引用入口。

1. 选择 **参考文献**，填写非空且唯一的 **文献键**和参考文献正文。
2. 把光标放到正文引用位置，选择 **引用**并填写同一文献键。
3. 将 **引用标签**留空，按当前文献表顺序自动编号；需要固定文字时填写自定义标签。
4. 使用 **编辑参考文献**修改文献键或正文。改键会同时更新所有使用该键的引用，自定义标签保持不变。

**删除参考文献**会保留正文引用并标记为未解析，不会自动删除引用文字。该操作可撤销。旧文件中有重复文献键时可以阅读，但必须先处理歧义，才能按键编辑或删除。

需要导入 RIS、维护独立文献库或从库中插入和更新引用时，使用独立的 Reference Manager，步骤见[阅读 PDF 与管理文献](/docs/editing/pdf-and-references.md)。

## 使用键盘和无障碍视图

用 `Tab` 和 `Shift+Tab` 在文本块与格式控件之间移动，在文本块内用方向键移动。标准撤销、重做和保存命令仍可使用。

文档获得焦点时，**打开无障碍视图**（**Open Accessible View**）可按文本阅读内容。按 `Escape` 关闭帮助或无障碍视图并返回文档。`accessibility.verbosity.document` 控制文档获得焦点时的无障碍帮助播报，默认开启。
