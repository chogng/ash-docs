# 打开和管理项目

在 Ash 编辑器窗口中，打开项目所在的文件夹，就可以浏览文件、搜索代码并使用项目工具。需要同时查看几个目录时，可以使用工作区文件组织它们。需要按目标整理资料时，使用 Agents 窗口中的**项目**。本文以桌面操作为主，并说明 SSH 与浏览器入口的区别。

本文对应当前源码中的功能。安装版本没有相关命令时，先核对版本。不同入口的多根范围见下文，目录选择与授权方式不能互相代替。

## 打开一个文件夹

1. 在编辑器窗口选择 **文件 → 打开文件夹...** （**File → Open Folder...** ）。也可以从欢迎页选择打开文件夹。
2. 选择项目目录。
3. 如果出现目录权限提示，核对路径，再按下一节选择允许的操作。
4. 在 **Explorer** 中确认文件树已切换到目标项目，再开始编辑或运行命令。

打开单个文件适合临时查看内容；需要项目搜索或集成终端时，应打开文件所在的项目文件夹。选择器中的取消操作会保留当前项目。

通过这个入口打开另一个目录会切换当前窗口的文件夹。若 Ash 提示先完成活动请求，请先回到当前任务，等待请求结束后再打开目录；阻止切换时，当前工作区会保持不变。

## 选择目录权限

打开尚无已保存授权的目录时，桌面应用会询问“是否信任此文件夹中的文件？”。这里的选择决定 Ash 对这个目录可以执行哪些操作。

| 选择 | 适合什么情况 | 允许的主要操作 |
| --- | --- | --- |
| **以只读模式打开**（**Open Read Only**） | 先检查下载或不熟悉的项目 | 浏览、搜索、读取文件和查看仓库 |
| **信任文件夹并启用开发功能**（**Trust Folder & Enable Features**） | 已确认项目来源，需要开发 | 在只读能力之外，修改文件、运行命令、更改仓库，并加载项目指令和配置等开发功能 |
| **取消**（**Cancel**） | 路径不对，或暂不打开 | 取消这次打开 |

确认之前，检查弹窗中的完整路径，尤其是名称相同的目录。已有目录授权时，可能不会再次显示选择提示。

状态栏中的 **只读文件夹**表示当前目录不可修改。**受限工作区**表示目录权限限制了部分功能。多根工作区中，各个目录的授权仍分别生效；把目录写进工作区文件不会自动授予访问权限。

选择状态栏的权限提示、横幅中的 **管理权限**，或运行 **管理工作区信任**（**Manage Workspace Trust**），可检查当前窗口的目录并确认更改权限。多根工作区需逐个选择文件夹；高级选项先保存为草稿，确认后才应用。详见[管理当前工作区的权限](/docs/configure/permissions.md#管理当前工作区的权限)。

目录授权、Agent 的动作批准和沙箱限制各自生效。启用开发功能不代表后续所有动作都会自动获准。

## 返回最近打开的项目

1. 在命令面板中执行 **Welcome**，打开欢迎页。
2. 在最近项目列表中找到需要的文件夹，核对它显示的路径。
3. 选择项目，等待文件树更新。

最近项目用于返回已打开过的位置，不保存项目文件的副本。目录被移动或删除后，需要通过 **打开文件夹...** 选择新位置。当前列表最多保留 12 个项目记录，包括文件夹和工作区文件。桌面窗口共享最近项目记录；浏览器入口保存在相应浏览器配置中。

要移除不再需要的记录，选择该行右侧的 **移除**（**Remove**）按钮。使用键盘时，按 `Tab` 聚焦该按钮，再按 `Enter` 或空格。此操作只移除最近记录，不删除项目文件，也不会关闭当前项目。文件夹记录移除后，仍可通过 **打开文件夹...** 重新打开；工作区文件可通过 **从文件打开工作区...** （**Open Workspace from File...** ）重新打开。

最近项目也支持已保存的多根工作区。工作区文件被移动后，用 **从文件打开工作区...** 选择新位置，并检查其中的相对目录路径。

## 在 Agents 中组织项目资料

在 Agents 窗口标题栏选择 **Chat / Agents** 后，左侧导航中的**项目**（**Projects**）把项目名称、目标和资料列表放在一起。它不是编辑器的多根工作区，也不是 [ChatGPT 的项目分组](/docs/agents/chatgpt.md#查找并整理会话)。创建项目不会打开新的执行目录，添加资料也不会把文件作为聊天附件发送。

本节对应已合入 `main` 的当前源码，不代表某个已发布安装包已包含这些入口。当前项目入口使用 `sessions.open.projects` 和 `sessions.show.projects`，无障碍提示设置为 `accessibility.verbosity.projects`。旧 `library` 命令和设置不是这些入口的别名；已有自定义快捷键需改用当前命令。若重开 Agents 窗口时保存的入口命令已不存在，会回到**聊天**，再从活动栏进入**项目**；这不是对旧入口的自动迁移。

### 创建和查找项目

1. [打开 Agents 窗口](/docs/getstarted/user-interface.md#打开和离开-agents-窗口)，在活动栏选择**项目**，再选择**新建项目**（**New project**）。
2. 在**你正在做什么？**中填写名称。名称不能为空，输入框最多接受 200 个字符。
3. 在**你希望达成什么目标？**中填写可选的目标描述。需要同时保存文件夹引用时，选择**使用文件夹**（**Use a folder**）。
4. 选择**创建项目**。确认页面显示项目名称、**项目目标**和**资料**。

项目列表中的**搜索项目**只按项目名称筛选，不搜索资料内容。**反转名称排序**切换名称排序方向。在项目页选择上方的**项目**返回列表。使用**编辑详情**（**Edit details**）修改名称和目标，再选择**保存更改**。

### 添加和使用资料

在项目的**资料**区域，使用以下操作：

* **添加文件**（**Add files**）：选择图片、PDF、文档或其他文件，可以一次选择多个文件。添加引用不保证 Ash 有该格式的专用编辑器。
* **使用文件夹**：添加文件夹引用，不将它变成工作区根目录，也不自动扫描或导入其中的全部文件。
* 选择资料名称：文件通过相应编辑器打开。文件夹进入文件选择器，再选择要打开的文件。
* **从项目中移除**：只移除该条引用，不删除源文件或文件夹。

一个项目最多保存 1,000 条资料引用。文件保留在原位置，项目不保存文件副本或内容版本。源文件移动、删除或失去访问权限后，引用可能无法打开。核对原路径，必要时移除旧引用，再添加当前位置。

添加资料不授予文件读取、写入或执行权限。若要让 Agent 使用这些内容，仍需在相应对话中明确提供文件或任务，并满足该会话的目录授权与动作批准要求。

### 确认当前入口和连接

本机桌面窗口使用系统文件选择器。连接 App Server 的浏览器入口使用服务器文件选择器，**添加文件**从当前服务器工作区选择文件，不会把本机文件上传到服务器。提示先打开文件夹时，先打开相应的已授权服务器目录，再返回项目页面。文件夹引用本身不能代替服务器目录授权。

项目名称、目标和资料列表由连接的 App Server 保存。没有连接的浏览器本地目录模式不能仅靠浏览器存储保存这些项目。这里也不是添加 SSH 工作区根目录的入口，远端工作区操作见 [SSH 远端项目](/docs/remote/ssh.md)。

加载失败时，检查连接并选择**重试**。

### 合并其他窗口的更改

编辑详情时，若提示项目已在其他窗口中更改，不必取消表单重写草稿：

1. 选择**重载并合并**（**Reload and merge**），读取最新项目。
2. 名称或目标在两个版本中被改成不同内容时，逐项选择**保留草稿**或**使用已保存的值**，也可以直接编辑该字段作为要保留的内容。
3. 检查合并结果，再选择**保存更改**。尚未解决全部冲突时，不能保存。

合并会保留最新已保存的资料列表，包括另一窗口新增或移除的引用，再加入当前表单选择的文件夹引用。重载失败时，草稿仍留在表单中，检查连接后重试。合并不会自动保存；关闭或取消表单仍会放弃未保存输入。

## 把编辑器放到单独窗口

需要在另一块显示器上查看文件时，可以为当前项目打开独立编辑器窗口。

1. 右键要查看的编辑器标签。
2. 选择 **Move into New Window**（移至新窗口），把该标签移出主窗口。需要在两个窗口都保留标签时，选择 **Copy into New Window**（复制到新窗口）。
3. 在新窗口继续编辑。要回到原来的布局，关闭这个独立窗口；移出的编辑器会回到主窗口。

命令面板中的对应命令名是 **Move to New Window** 和 **Copy to New Window**。需要一次移出整个编辑器组时，使用 **Move Editor Group into New Window**；**Copy Editor Group into New Window** 保留原组。

复制的是编辑器视图，文件内容和未保存更改仍然共享。它不会生成文件副本，也不会建立新的项目工作区。要保留另一份内容，应显式另存文件。

独立窗口标题栏的 **Turn On Compact Mode**（开启紧凑模式）会隐藏标签栏、状态栏和搜索入口，给正文留出更多空间。选择 **Turn Off Compact Mode** 恢复；主窗口的布局不受影响。桌面上的 **Switch Window...** 可以切换到这些窗口。

浏览器入口可能拦截新窗口。出现相关提示时，检查浏览器是否允许当前站点打开弹出窗口，然后重试。

## 选择启动时恢复哪些窗口

打开[设置](/docs/configure/settings.md)，搜索 `window.restoreWindows`，选择 **Restore windows**：

| 值 | 启动时的行为 |
| --- | --- |
| `all` | 恢复上次的所有窗口，默认选项 |
| `folders` | 恢复包含文件夹或工作区的窗口 |
| `one` | 恢复上次活动的窗口 |
| `none` | 不恢复上次的窗口 |
| `preserve` | 即使启动时指定了新文件夹或工作区，也保留恢复上次窗口的行为 |

通常，启动时明确指定文件夹或工作区会优先于普通恢复设置；`preserve` 保留上次窗口。应用更新后的重新启动会按恢复全部窗口处理。

恢复窗口与恢复 Agent 对话是不同操作。需要继续已有任务时，按[会话与任务](/docs/agents/sessions.md)选择相应会话。桌面终端的退出恢复会创建新 Shell，不会继续旧命令，详见[退出应用后恢复终端](/docs/terminal/basics.md#退出应用后恢复终端)。

## 使用多根工作区

多根工作区把几个文件夹放在同一个编辑器窗口中，适合一起查看前端、后端或共享代码。工作区文件支持 `.ash-workspace` 和 `.code-workspace`，格式为 JSONC。

| 入口 | 可以组合的目录 | 工作区文件的位置 |
| --- | --- | --- |
| 本地桌面窗口 | 本机目录 | 本机文件 |
| 桌面 SSH 窗口 | 同一已连接 SSH 主机上的目录 | 本机文件，保存远端目录 URI |
| 浏览器本地目录模式 | 经该浏览器选择并授权的本机目录 | 经浏览器授权的目录；临时工作区保存在浏览器配置中 |
| 连接 App Server 的浏览器入口 | 同一服务器上为当前 Web 会话授权的目录 | 已授权的服务器目录；临时工作区保存在浏览器配置中 |

SSH 工作区不能混合本地目录或不同主机的目录，也不能直接把工作区配置文件保存到远端。完整步骤见[组织同一 SSH 主机的多个目录](/docs/remote/ssh.md#组织同一主机的多个目录)。

### 添加、移除和保存文件夹集合

以下步骤以本地桌面目录为例。浏览器入口使用相同的工作区命令，本地目录由浏览器选择和授权，服务器目录由服务器确认授权。

1. 打开第一个项目文件夹。
2. 从 **文件** 菜单或命令面板执行 **将文件夹添加到工作区...** （**Add Folder to Workspace...** ），选择其他本地目录。
3. 如果出现权限提示，逐个核对目录并选择允许的操作。确认 Explorer 中出现需要的根目录。
4. 执行 **将工作区另存为...** （**Save Workspace As...** ），选择便于下次查找的位置，例如 `team.ash-workspace`。

从单个文件夹添加其他根时，Ash 先创建临时工作区文件。使用另存为给这组目录一个明确的位置；保存的是目录引用和工作区配置，不是项目文件副本。另存到其他位置时，Ash 会重新计算目录相对路径，并保留 `settings`、`tasks`、`launch` 等其他配置。

要移除一个根，执行 **从工作区移除文件夹...** （**Remove Folder from Workspace...** ），按名称和路径选择目标。移除只改变工作区中的目录集合，不删除磁盘文件。取消选择会保留原集合。

也可以在 **Explorer** 的工作区根节点上打开右键菜单，选择添加或移除文件夹。只剩一个根的工作区仍保留该根节点；子文件或子文件夹上的操作不代替移除工作区根。

要重新打开已保存的集合，执行 **从文件打开工作区...** ，选择对应文件，也可以从最近项目进入。

### 编辑工作区文件

执行 **打开工作区配置文件**（**Open Workspace Configuration File**），可以查看和编辑当前工作区。一个包含两个目录的例子是：

```json
{
  "folders": [
    { "path": "./frontend", "name": "前端" },
    { "path": "./backend", "name": "后端" }
  ]
}
```

`path` 相对于工作区文件所在目录解析，也可以使用本地绝对路径；`name` 是可选的显示名称。上述例子要求工作区文件旁确实存在 `frontend` 和 `backend` 两个文件夹。

保存后，Ash 自动更新根目录和文件树，不需要关闭再打开。用其他编辑器保存这份文件也会触发更新。更改 `name` 可调整显示名称，更改数组顺序可调整根目录顺序；这些操作不重命名磁盘目录。

遇到无效路径、配置错误或授权取消时，先检查错误信息。未被接受的外部编辑会保留上次可用的目录集合；修正后再次保存工作区文件。文件已被其他程序修改时，先比较版本，不要直接覆盖。

如果移除根目录，或添加嵌套根目录会改变未保存文件的目录归属，Ash 会要求先保存或还原这些文件。工作区配置文件自身有未保存修改时，也应先处理，再使用添加、移除或另存命令。

### 运行命令前确认目标目录

新终端优先使用当前编辑文件所属的根；无法确定时会请你选择，取消不会自动选用第一个根。拆分终端沿用原终端所属的根。调整根目录显示顺序，或增删其他根，不会把保留根中的已有终端切换到另一个项目。

多根工作区不会创建 Git 分支或 worktree，也不会自动扩大 Agent 的执行权限。会话仍有自己的执行目录；出现 **Select a folder for this session** 时，明确选择该会话的目录。目录授权、Agent 批准和沙箱限制仍分别生效。

多根集合中的目录必须符合当前入口的范围。修改编辑器设置时，先选择用户、工作区或具体文件夹目标，确认配置保存的位置，见[调整设置](/docs/configure/settings.md#当前配置范围)。

### 从桌面启动入口打开

也可以将下面的参数传给当前使用的 **Ash 桌面启动入口**，并替换为工作区文件的实际绝对路径：

```text
--workspace "/absolute/path/team.ash-workspace"
```

这里是桌面应用的启动参数。Ash Code 终端界面的 `ash` 命令、源码启动脚本和打包后的桌面可执行文件并非同一个入口；使用与你的安装方式匹配的桌面入口。需要准备源码环境时，先阅读[从源码运行](/docs/getstarted/run-from-source.md)。

## 关闭当前项目

在编辑器窗口选择 **文件 → 关闭文件夹**，使用工作区文件时则选择 **关闭工作区**。这会让当前窗口回到空工作区，不会删除磁盘上的项目文件。

如果出现未保存更改提示，先决定保存、放弃还是取消关闭。再次打开项目时，仍需确认当前目录和文件内容，避免把窗口恢复当作文件备份。

## 浏览器入口有什么不同

浏览器入口能打开什么目录取决于当前连接方式。

### 浏览器本地目录模式

支持本机目录选择的浏览器会请求文件访问许可。使用上面的添加、移除和另存命令管理多根目录；添加时逐个选择目录，选择完成后结束添加。另存时先选保存目录，再填写工作区文件名。

保存后可以使用 **从文件打开工作区...** 或最近项目重新打开，也可以刷新当前页面恢复工作区。Ash 会重新读取配置并检查各目录的浏览器权限。跨目录引用依赖当前浏览器配置中的授权记录；把工作区文件复制到另一个浏览器或电脑，不会自动带上这些权限。无法打开时，先在当前浏览器重新选择并授权对应目录，不要把桌面绝对路径直接填入浏览器工作区。

创建或另存当前工作区会保留当前打开的编辑器和未保存内容。打开另一个已保存的工作区时，Ash 会处理当前编辑器的关闭提示，再恢复目标工作区记录的编辑器和可用备份，无需另行刷新。恢复依赖该浏览器仍保留的存储和文件访问权限，不能代替保存文件。

临时工作区和未保存内容依赖当前浏览器存储。另存为可以保存目录集合，但不能代替保存项目文件；清理浏览器数据前，先保存需要保留的内容。

### 连接服务器的浏览器入口

连接 App Server 的浏览器入口支持同一服务器上的已授权多根目录。运行 **将文件夹添加到工作区...** 并在服务器目录选择器中逐个选择目录，再选择带有已选数量的完成项。新增的未授权目录需要在服务器电脑上的 **Ash: Authorize Server Folder** 提示中批准；取消或拒绝会保留上次接受的目录集合。

使用 **将工作区另存为...** 保存目录集合时，文件写到当前已授权的服务器位置；临时工作区仍依赖浏览器存储。使用 **从文件打开工作区...** 重新打开配置时，其中的目录仍需满足当前 Web 会话的授权。刷新页面会读取服务器已确认的工作区集合，不会仅凭配置文件内容扩大权限。

移除一个根会撤回该 Web 会话对这个根的目录访问。工作区配置文件即使留在被移除的根内，只要仍满足当前读取权限，就可以继续访问该文件；这不保留对同目录其他文件的访问。Web 会话的目录集合独立于桌面窗口，在浏览器里增删根不会同步修改桌面工作区。

服务器收紧目录授权后，已有 Web 授权不能保留被撤回的能力。目录降为只读时，仍获准的文件读取和其他根目录继续可用，被撤回的写入与执行能力不再可用。随后删除限制配置或放宽设置，也不会自动恢复这个 Web 会话原来的写权限，需要重新取得相应授权。保存失败时，先保留未保存内容并核对目录权限；不要把页面重连当作权限已经恢复。

通过 **打开文件夹...** 切换单个服务器目录时，浏览器仍会显示 **Authorize Server Folder**；超出当前许可范围的目录也需要服务器电脑批准。服务器路径与自己电脑上的同名路径可能不同，不能混入浏览器本地目录或其他服务器的目录。浏览器目录许可、服务器授权和 Agent 的动作批准各自生效。

如果提示工作区已更改、授权确认将在重连后重试，先核对当前文件树，等待重连或刷新完成后再继续。会话已关闭时，重新打开经过认证的服务器入口。不要把网络错误后的重复添加当作恢复权限的办法。
