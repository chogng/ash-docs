# 阅读 PDF 与管理文献

在 Ash 中，你可以阅读和批注 PDF，将 RIS 文献记录整理为本地文献库，再把引用插入 Academic 论文。本页说明需要的独立扩展、文件保存方式，以及文献库与论文之间的连接。

本页依据 2026 年 10 月 20 日的主分支实现。扩展市场、发行版本和后端平台是否提供对应包，以实际发布内容为准。

## 安装需要的扩展

这三项能力分别安装，不会因为安装其中一个而自动具备另外两个：

| 要做什么 | 扩展 | 扩展 ID |
| --- | --- | --- |
| 阅读 PDF，添加高亮、墨迹和批注 | **PDF 查看器**（**PDF Viewer**） | `ash.pdf-viewer` |
| 导入 RIS，管理文献库和 PDF 关联 | **文献管理器**（**Reference Manager**） | `ash.reference-manager` |
| 编辑论文，接收文献库引用 | **学术论文（实验性）**（Academic (Experimental)） | `ash.academic` |

1. 运行 **打开扩展**（**Open Extensions**），搜索所需扩展。
2. 核对来源、版本与后端平台，安装对应包。PDF 和文献管理器的发行包 ID 分别为 `ash/pdf-viewer`、`ash/reference-manager`。
3. 检查 **启用**状态，再按提示审阅该精确版本的 **授权执行**。
4. 回到文件树打开相应文件。

安装、启用和执行授权是不同步骤。授权范围及独立后端要求见[启用文档编辑器](/docs/editing/documents.md#启用文档编辑器)。搜索不到包时，先核对发布内容，不要安装来源不明的同名包。普通 Code 和 Agents 产品包不内置这两项可选资源编辑器。

Academy 导出 PDF 不依赖 PDF 查看器。在线文献检索则由提供相应工具或 Skill 的 Plugin 负责，文献管理器不是在线搜索服务。

## 阅读 PDF 并保存批注

从文件资源管理器打开 `.pdf`。PDF 查看器保留原始 PDF 字节，通过单独文件保存批注，不会把 PDF 转换为可编辑的 `.ash-doc`。

1. 在工具栏选择 **高亮**、**绘制**或 **批注**，在页面上添加标记。
2. 用 **颜色**调整标记颜色。选择批注后，在 **所选批注**中编辑文字，离开输入框应用修改。
3. 按需使用工具栏的 **撤销**、**重做**或 **删除**。
4. 选择 **保存**，确认状态显示 **批注已保存**。

批注保存到 PDF 旁边的配套文件。例如，`paper.pdf` 的批注文件是 `paper.pdf.ash-annotations.json`。重新打开同一 PDF 时会读取已保存批注。需要把批注带到另一位置时，应同时保留 PDF 和配套文件及其对应名称；单独交付 PDF 不会包含这些标记，其他 PDF 软件也不会自动读取 Ash 的配套格式。

> [!IMPORTANT]
> 关闭或停用扩展前，先保存批注。未保存批注只属于当前视图，不能依赖文档自动备份恢复。撤销授权、停用或替换扩展后，已有页面和批注草稿会冻结；重新启用再打开文件使用新编辑器，但不会把旧视图的未保存批注自动带过去。

Chat 中的 PDF 附件预览使用只读快照，不读取文件旁的批注文件，也不能在预览中修改批注。没有 PDF 查看器时，附件仍保留下载或打开操作，不会切换到另一个内置阅读器。

扫描 PDF 没有可提取文字时，需要独立的 OCR 能力。PDF 查看器本身不提供 OCR，也不把批注嵌入原始 PDF。

## 从 RIS 创建文献库

1. 打开一个 `.ris` 文件，进入 **文献库**编辑器。
2. 检查导入的标题、作者、年份、DOI 和其他字段。
3. 选择工具栏的 **文献库另存为**（**Save library as**）。
4. 选择新的 `.ash-library` 文件位置，确认保存成功。

原始 RIS 不会被覆盖。另存为要求新文件名，不覆盖已有文献库。没有 RIS 时，可以先打开一个空白的 `.ash-library` 文件，再添加文献；已有文献库工具栏中的 **新建文献库**也可创建另一个库。这些是编辑器中的按钮，不是全局命令面板命令。

RIS 应使用 UTF-8 编码。单次导入最多 8 MiB、10,000 条记录；格式或大小不符合要求时，导入会在修改文献库前停止并给出错误。

## 整理和保存文献

* **导入 RIS**：把更多记录合并到当前库。相同 DOI 的记录会去重，DOI 比较忽略大小写并识别 DOI 链接；没有 DOI 时，使用规范化后的类型、标题、年份和作者判断。重复导入不会覆盖已有条目的元数据。
* **添加文献**和 **编辑文献**：修改引用键、作者、刊物、摘要和关键词等字段。多个作者或关键词用分号分隔；同一库内的引用键必须唯一。
* **搜索文献**：筛选库中的元数据，不是 PDF 全文检索或在线检索。
* **删除文献**：确认后从库中移除条目，已经插入论文的引用与书目内容仍保留。

有保存位置后，元数据修改会自动保存。仍可选择 **保存文献库**明确保存，并检查状态和错误，不要把输入完成当作保存成功。

其他窗口已修改同一文件时，写入冲突会保留当前未保存草稿。用 **文献库另存为**保存到新文件，或核对已保存版本后选择 **重新加载文献库**；后者会要求确认放弃未保存修改。

另存为或直接复制文献库会保留库和条目的身份，不会创建逻辑上全新的库。不要把逐渐分歧的两个副本同时当作同一篇论文中的独立来源。

扩展失效时，保留冻结的文献库视图。重新启用扩展后，在旧视图仍打开的情况下重新打开资源，可以把保留的未保存工作副本交给新编辑器。确认内容和保存结果后再关闭旧视图；冻结的编辑器本身不能保存。

## 在 Academic 论文中插入引用

此流程用于 `.ash-academic` 和 `.ash-paper` 论文。普通 `.ash-doc` 文档和频道笔记不提供这个文献库引用接口。

1. 保存文献库，处理所有未保存状态和错误。
2. 选择 **打开 Academy 文档**，在文献库旁打开要编辑的论文。
3. 在论文中放置插入光标，再回到文献库。保持论文编辑器在旁边可见。
4. 在 **Academy 文档**列表中核对目标论文。
5. 选择一条文献，再选择 **插入引用**。
6. 检查论文中的引用和书目，再保存论文。

插入操作在一个论文撤销步骤中添加或复用关联书目，并插入引用。论文只读、扩展失效、文献库未保存或目标不可用时，操作不会继续。

在文献库修改条目并保存后，选择 **更新引用**，可一起更新目标论文中已关联的书目文字和引用键。这也占一个论文撤销步骤；显式设置的引用标签保留。删除库中的条目不会删除论文内容，更新时会报告缺失的条目。

链接按文献库和条目的稳定身份建立，不只依赖文件名或可修改的引用键。引用键与无关条目冲突时，应先处理错误，不要靠重复插入绕过检查。保存原生论文格式才能持久保留这些关联；导出到其他格式再导入，不保证私有关联仍在。

## 给文献关联 PDF

选择一条文献，再选择 **关联 PDF**，选取有访问权限的 PDF 文件。这里保存文件链接，不复制或下载 PDF，也不会自动下载 RIS 中的附件地址。

**打开 PDF**使用单独安装、启用并授权的 PDF 查看器打开第一份关联附件。其他附件仍列在条目详情中。移动或删除原文件、撤销文件权限后，链接可能无法继续打开。

文献管理器不从 PDF 提取元数据，也不提供 CSL 样式选择、BibTeX 或 EndNote 导入导出、云同步及全文搜索。

## 使用键盘和无障碍视图

在 PDF 中，`Tab` 可到达工具、页面与批注字段。聚焦页面后，用方向键移动批注光标；`Enter` 放置批注，或开始、结束高亮与墨迹；`Escape` 取消绘制。批注列表支持方向键、`Home` 和 `End`。

文献库中，`Tab` 可到达工具栏、目标论文、搜索、条目与详情。在文献列表中用方向键、`Home` 和 `End` 移动，按 `Enter` 选择。

**打开无障碍视图**读取 PDF 提取文字与批注，或文献库元数据和摘要。`accessibility.verbosity.resourceEditor` 控制聚焦资源编辑器时的帮助提示。物理辅助技术、完整 Electron 多窗口、远程文件及其他操作系统仍有单独验收范围，先在实际环境中检查关键流程。
